## 本文

国立国語研究所
広報ご担当者様

突然のご連絡失礼いたします。
韓国で日本語学習アプリを個人開発しております、【氏名】と申します。

このたび、開発中のアプリ内で貴研究所の名称を使用させていただきたく、ご相談のためご連絡いたしました。

### 1. アプリの概要

- アプリ名：Hareru（晴れる）
- 内容：JLPT（日本語能力試験）合格を目指す方向けの日本語語彙学習アプリです。忘却曲線に基づく復習スケジュール（FSRS）を用いて、単語・漢字・例文を効率よく記憶できるよう設計しています。
- 対象：韓国語話者の日本語学習者
- 配信予定：【App Store / 配信開始予定時期】
- 収益形態：【無料 / 有料 / アプリ内課金 / 広告 など】

### 2. 名称を使用したい場面

アプリ内に、学習の成果に応じて研究所が発展していく経営シミュレーション形式のゲームを搭載する予定です。

物語の舞台は架空の未来（2XXX年）の日本です。人々が脳内通信で会話するようになり、漢字が次第に使われなくなった世界で、「国立国語研究所」が漢字と日本語を守る最後の拠点として登場します。

物語は、規模が小さくなった研究所から始まり、プレイヤーが実際に日本語を学習するほど研究所が再び発展し、失われた漢字が社会に戻っていくという内容です。最終的には、日本語と漢字の価値を再発見し、研究所が言葉の再興の中心となる結末を予定しております。

貴研究所の活動や社会的意義を損なう意図は一切なく、むしろ日本語と漢字を守り伝えることの大切さを、学習者に親しみやすく伝えることを目的としております。

### 3. ご許可をお願いしたい範囲

以下の項目について、それぞれご可否をお伺いできれば幸いです。

1. ゲーム内テキストにおける名称「国立国語研究所」および略称「NINJAL」の使用
2. ロゴマーク・建物外観など視覚的表現の使用（※ご許可がない限り使用いたしません）
3. 上記を含むアプリの商用配信（【収益形態】）

### 4. 配慮事項

- アプリ内に「本作はフィクションであり、実在の国立国語研究所の活動・見解とは関係ありません」といった注記を表示いたします。
- 研究所の描写について修正のご要望があれば、可能な限り対応いたします。
- 公開前に該当部分の画面や文章をご確認いただくことも可能です。

- アプリ画面のスクリーンショット
