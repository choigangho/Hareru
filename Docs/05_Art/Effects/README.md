# 연구소 픽셀 이펙트 (2026-11-01)

AI 생성 대신 **스크립트로 프레임을 직접 그림** (`tools/fx_author.py`): 프레임마다 모양이 흔들리지 않고, 게임 팔레트(호박색 · 청록 · 먹 남색 · 화지 흰색 · 먼지 베이지)를 그대로 씀. Higgsfield 크레딧도 쓰지 않음.
사라질 때는 투명도 대신 **순서 디더링(Bayer 4×4)** 으로 픽셀을 덜어내서 끝까지 또렷함. 밀도는 다른 에셋과 같음 (방 픽셀 1칸 = 2칸).
앱 번들 사본은 `Sources/Hareru/Resources/Art/Effects` (가로 스트립), 코드는 `OfficePixelArt.Effect` · `OfficeScene.playEffect`.

| 스트립 | 프레임 | 언제 |
| :--- | :--- | :--- |
| `fx_dust` | 6 × 56×24 | 시설 착지 (낙하 연출 70% 지점, 한 번) |
| `fx_sparkle` | 7 × 48×48 | 콤보 성립 버블이 뜰 때 |
| `fx_ink` | 8 × 56×56 | 한자 복원 완료 버블이 뜰 때 — 먹 한 방울이 번져 고리 + 종이빛 |
| `fx_motes` | 6 × 32×40 | 研究P 정산 버블이 뜰 때 — 청록 입자 상승 |
| `fx_drip` | 10 × 16×48 | 양동이 소품 위 천장 누수, 계속 반복 (쇠퇴한 연구소 분위기) |

'동작 줄이기' 설정이면 일회성 이펙트는 재생하지 않고 누수도 숨김. 같은 스크립트가 메뉴 아이콘(`icon_menu_16/24`)도 그림.
