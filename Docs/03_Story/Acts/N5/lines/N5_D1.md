# N5 · 1일차 — 대사 데이터 (한 줄 단위)

> 장면 설계: [`../N5_SCRIPT.md`](../N5_SCRIPT.md) §3. 이 파일이 **게임에 들어갈 실제 줄**. 그대로 JSON으로 옮길 수 있게 열을 고정.
> 열: `ID` · `화자` · `표정` · `일본어` · `한국어` · `단어` · `비고` (연출 · 조건 · 입력)
> `단어` 열 (Design/SPEECH_DECAY §5): 일본어 줄에 나오는 학습 단어 `word id@시작-끝`, 여러 개는 `, `로. 범위는 일본어 칸에서 후리가나 `(…)`를 뺀 글자 기준, 0부터 · 끝 제외. 활용형은 활용된 모양 전체를 잡음 (例 `来た`). 『』 강조와 말 잃기가 같은 태그를 씀. 현재 D1만 태그 — 나머지는 P2 보조 도구로.
> 비고 `필수` = 말 잃기 예외 (반전 · 복선 · 조작 안내 줄).
> 화자 종류: 인물 이름 · `독백`(주인공 속마음, 음성 없음) · `타자`(인트로 타이핑) · `입력`(입력창) · `선택`(선택지) · `시스템`(UI 문구) · `연출`(대사 없는 컷)
> 일본어 열이 있으면 음성 재생 + 한국어는 누르면 보이는 뜻. 일본어 열이 비면 한국어가 대사.
> 톤(주임 음성): 비고 칸 `톤:fast`(설명 폭주) · `톤:surprised` · `톤:flustered` · `톤:excited`. 표시 없으면 기본(차분·빠른 말투). 반전은 드물게.
> 변수: `{이름}` · `{시험}`(초기 설정의 응시 회차, 예: 12월) · `{목표}`(목표 급수) · `{남은일}`(시험까지 남은 날) · `{출근}`(알림 시각)
