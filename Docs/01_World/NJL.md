## 기관 · 분위기

- **시대**: 2XXX년 일본. 뉴럴링크가 보편화되어 사람들은 공용 말로 말하고 일본어는 칩 통역에 맡김 (D-16).
- **쇠퇴의 흐름**: 전통 언어 사용 감소 → 어려운 한자부터 사라짐 → 결국 한자 자체가 잊혀짐.
- **무대**: **国立言語遺産研究所 (국립언어유산연구소, NJL)** — 가상 기관. 영향력이 줄어 국가 지원은 최소, 연구는 로봇(하드웨어)과 AI(소프트웨어)가 하지만 **법적으로 사람 1명은 상주해야 함** → 그 1명이 주임 연구원. 게임은 그녀 혼자 지키던 연구소에 **주인공이 신입으로 배정되는 날**부터 시작 → **시작 인원 2명** (주임 연구원 + 신입).
- **분위기**: 시작은 '흐림'. 연구소가 성장할수록 연구소 위 하늘이 갬 → 앱 이름 **晴れる**와 직결.
  - (2026-11-04 D-11: 실시간 날씨는 보류 — 하늘은 이 '연구소 날씨'만 쓴다.) 앱의 실제 날씨 엔진과 별개로, 게임 안 연구소 하늘은 **연구소 영향력**으로 정해지는 '연구소 날씨'를 가짐 (흐림 → 갬 → 쾌청).

### 5.1 연구소 성장 단계 (= 급수 챕터)

| 단계 | 공간 | 급수 연동 | 연구소 날씨 |
| :---: | :--- | :--- | :--- |
| 1 | 낡은 사무실 한 칸 (책상 하나, 고장 난 로봇) | N5 | 흐림 · 비 |
| 2 | 사무실 층 전체 | N4 | 흐림 |
| 3 | 연구동 건물 | N3 | 구름 조금 |
| 4 | 연구 캠퍼스 (서고 · 녹음 스튜디오 · 강의동) | N2 | 맑음 |
| 5 | 국가 언어 재건 본부 | N1 | 쾌청 → **晴れる 진엔딩** |

단계 승급 조건 = 해당 급수 단어 일정 비율 암기 + 영향력 + **승급 심사 이벤트(그 급수 모의고사)**.

## 11. 기관명 — 国立言語遺産研究所 (NJL)

- **가상 기관**: 国立言語遺産研究所 (こくりつげんごいさんけんきゅうじょ, 국립언어유산연구소). 약칭 **NJL**.
- **이름에 담긴 뜻**: 한자와 '말로 하는 일본어'를 모두 **유산(遺産)** 으로 지키는 곳 → 말(음성) 보존과 한자 복원이라는 두 축을 한 이름으로 설명.
- **개발 원칙**:
  - 기관명·약칭은 코드에 직접 쓰지 않고 **게임 문자열 데이터 한 곳(`institute.name`)** 에서만 관리.
  - 앱 안에 "본 게임은 픽션이며 실존 인물·단체와 관계없습니다" 고지.
  - 출시 전, 같은 이름·약칭(NJL)을 쓰는 실존 단체나 등록 상표가 없는지 한 번 검색해 확인.
