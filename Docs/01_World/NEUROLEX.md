### 1.3 NeuroLex 설정 (2026-11-04)

> 실존 기업 · 상표와 겹치지 않는 가상 기업. 이 절이 NeuroLex의 원본. 부서 · 본사는 2026-11-04 소유자 확정. **[미정]** 은 아직 확정 전.

**한 줄**: 칩과 렉스코드를 만든 거대 신경망 기업. 대중에겐 "말 없이도 통하게 해 준 편리한 회사", 실제로는 언어압축부를 통해 한자(모호한 언어)를 의도적으로 지워 온 회사.

#### 겉모습 — N5부터 써도 되는 상식
| 항목 | 내용 |
| :--- | :--- |
| 하는 일 | 뇌에 심는 칩(뉴럴 통신 칩) · 렉스코드 규격 · 번역 레이어를 만들고 운영 |
| 대표 사건 | 2079년 「바벨 패치」 — 뇌파 통신 프로토콜 일괄 배포. 대중에겐 '말 없이 통하는 시대'의 시작으로 기억됨 |
| 렉스코드 | NeuroLex 표준 도트 글자. 보면 칩의 번역 레이어가 뜻을 띄움. 간판 · 문서 · 포장이 모두 렉스코드 |
| 제품 등급 | 대중용 저가 칩(광고 강제 주입 · 기억 변조에 취약) / 양자 암호화 고급 칩(비쌈) — §1.2와 같음 |
| 광고 문구 | 「考(かんが)えるだけで、伝(つた)わる。」 (생각만으로, 전해진다.) — 칩 광고 · 전단 · 꿈속 광고 개그(D1 설정 장면)에 씀 |
| 로고 | 렉스코드 도트로 만든 L 한 글자, 청록색 (창밖 간판과 같은 색) |
| 대중의 인식 | 한자를 못 읽게 된 건 칩에 적응한 자연스러운 세대 변화 (백화라는 말도 대중은 모름) |
| 주인공과의 관계 | 주인공이 다니다 한 달 전 잘린 회사 (D1 인트로에서 공개). 퇴사 조건 = 업무 기억의 영구 소거 + 칩 제거 (가족 기억도 몰래 지운 건 비밀) |

#### 쓰는 규칙
- N5 대사 · 예문: 회사 이름 · 칩 · 렉스코드 · 광고 · 주인공이 잘린 사실까지만. 입사 목적 · 백도어 · 언어압축부 · 의도된 백화는 금지 (N5_SCRIPT §4).
- 주임은 회사 얘기를 피하지 않지만 판단을 말하지 않음 ("…그렇죠. 편하죠.").
- 회사를 처음부터 악당으로 그리지 않음 — 칩은 실제로 편리하고, 구시가지 사람들도 칩을 미워하지 않음. 무서운 건 '편리함'이라는 점이 N2 반전의 무게.
- **[미정]** 흑막과 NeuroLex의 관계 (이사 위의 인물인지, 회사 밖인지).
