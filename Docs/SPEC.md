# Hareru (晴れる) — 상세 설계 명세서 (`SPEC.md`)

본 문서는 `Hareru`의 최신 사용자 경험, 3탭 구조, 날씨 연동 글라스 UI, FSRS 기억 알고리즘, 온보딩 진단 시스템 및 데이터 구조 명세서입니다.

---

## 1. 앱 아키텍처 & 플로팅 3탭 순환 구조

Hareru는 기존의 게임 탭, 성우 도감, 손글씨 처방 노트 등의 부가 요소를 정리하고, **매일 날씨앱을 확인하듯 자연스럽게 일본어 어휘를 습득하는 3탭 구조**로 통합되었습니다.

```
┌────────────────────────────────────────────────────────┐
│                      Hareru App                        │
│                                                        │
│  [온보딩 (최초 1회)]                                    │
│   1. 소셜/이메일 계정 가입·로그인 (Apple/Google/Email)      │
│   2. 목표 JLPT 급수 & 가장 가까운 2개 시험일 선택          │
│   3. 10문항 4지선다 어휘력 진단 테스트                   │
│   4. 일일 권장 암기 계획 확인 & CoreLocation 위치 허용      │
│                                                        │
│  [메인 화면]                                           │
│   ┌───────────────┬────────────────┬────────────────┐  │
│   │  탭 1 · 학습   │   탭 2 · 통계   │   탭 3 · 설정   │  │
│   │  (Study Deck) │  (3D Heatmap)  │   (Settings)   │  │
│   └───────────────┴────────────────┴────────────────┘  │
│          ▲ 플로팅 Liquid Glass 캡슐 탭 바 (하단)        │
└────────────────────────────────────────────────────────┘
```

### 1.1. 하단 네비게이션: iOS 26 플로팅 Liquid Glass 캡슐 탭 바
- 시스템 기본 `UITabBar`를 배제하고 화면 하단에 떠 있는 투명 글라스 캡슐 바([`FloatingGlassTabBar`](../Sources/Hareru/Components/FloatingGlassTabBar.swift)) 적용.
- 선택된 탭 뒤로 볼록 렌즈 굴곡 인디케이터가 `matchedGeometryEffect`와 스프링 물리로 부드럽게 미끄러지며 이동.
- 하늘 명도 및 기상 상태에 따라 글라스 틴트 및 텍스트 대비가 유동적으로 자동 조정됨.

## 2. 탭별 상세 명세

### 2.1. 탭 1 · 학습 (`Features/Study`)
학습 탭은 카드가 바로 노출되어 사용자를 압박하지 않으며, **대시보드 개요**를 거쳐 몰입 카드 덱으로 진입합니다.

1. **학습 전 개요 대시보드 (`studyOverviewDashboardBody`)**:
   - 목표 급수(N1~N5) 및 공식 시험 회차 D-Day 배지 표시.
   - 10문항 진단 결과 및 누적 학습 로그를 결합한 **실시간 일일 권장 암기량(예: 하루 24단어)**과 소화 가능 속도 동향(여유 / 완주 가능 / 빠듯함) 안내.
   - 이전 학습 요약(외운 단어 수, 오늘 학습 수, 복습 대기 수) 확인 후 `[이어서 학습하기]` 또는 `[새 세션 시작]` 선택.

2. **단어 카드 인터랙션 ([`WordCardView`](../Sources/Hareru/Features/Study/WordCardView.swift))**:
   - **카드 앞면 (정답 전)**:
     - 표제어: 시험지 인쇄 명조체([`JLPTFont.termMincho`](../Sources/Hareru/Components/JLPTFont.swift)) 50pt로 강렬하게 렌더링.
     - 예문: 힌트 과잉을 막기 위해 **후리가나와 한국어 해석이 없는 순수 일본어 원문(고딕체)**만 제공. 발음 힌트 및 스피커 버튼 숨김.
     - 상단 헤더: `12 / 30` 형태의 간결한 진도 카운터.
   - **정답 보기 및 뒷면 해금**:
     - `정답 보기` 클릭 시 표제어 발음(히라가나), 품사, 한국어 뜻, 어절 묶음 후리가나 예문, 분할 한국어 해석([`SplitText`](../Sources/Hareru/Components/SplitText.swift)), `256kbps` 사전 제작 성우 오디오 자동 재생.
     - 한자 개별 터치: 정답 공개 후 표제어 내 한자만 개별 탭하여 1단계 팝오버(음훈·현재 발음 강조) 및 2단계 상세 시트([`KanjiDetailSheetView`](../Sources/Hareru/Features/Study/KanjiExplorationViews.swift)) 탐색 가능.
     - 다의어(Polysemy): 카드는 1장으로 유지하며 서브 의미(뜻 2~4)는 정답 공개 후 카드 하단에 함께 노출.
   - **고정 액션 슬롯 모핑**:
     - 카드 최하단에 높이(`58pt`)가 고정된 액션 슬롯 배치.
     - 다의어 등으로 카드 본문이 길어져도 스크롤은 본문 안에서만 일어나며, 하단 버튼은 엄지손가락 위치에 항상 고정.
     - `[정답 보기]` 버튼 1개가 동일한 자리에서 **`[모르겠음]` · `[애매함]` · `[알고있음]` · `[쉬움]` 4개 평가 버튼**으로 자연스럽게 분할 변형됨.
   - **세션 완료 연출 (`晴れる Clear`)**:
     - 당일 세션의 모든 카드를 해결하면 구름이 걷히고 황금빛 햇살이 쏟아지는 [`HareruClearCelebrationView`](../Sources/Hareru/Components/HareruClearCelebrationView.swift) 축하 애니메이션 발동.

### 2.2. 탭 2 · 통계 (`Features/Insights`)
복잡한 수치 대신 성실도와 직관적인 학습 성과를 시각화합니다.

1. **최상단 3D 글라스 잔디 히트맵 ([`GlassGrassHeatmapCard`](../Sources/Hareru/Features/Insights/InsightsHubView.swift))**:
   - 최근 14주(일요일 시작 7×14 격자) 학습 잔디 렌더링.
   - 일일 학습 어휘 수에 따라 0~4단계 입체 베벨(돌출 깊이 + 상단 하이라이트)로 3D 표현.
   - 잔디 블록 터치 시 미니 말풍선 팝오버(날짜, 그날의 날씨 아이콘, 암기한 단어 수) 표시.
   - 우측 상단 연속 학습 스트릭(예: `14일 연속 🔥`) 카운터.
2. **핵심 요약 4칸 메트릭**:
   - 외운 단어 (누적 암기 완료 수 / 전체 카탈로그 수).
   - 평균 기억 유지율 (FSRS Retrievability 백분율).
   - 평균 반응 시간 (카드 확인까지의 평균 초).
   - 누적 평가 횟수.
3. **4버튼 평가 분포**:
   - 사용자가 직접 누른 4버튼(`모르겠음`, `애매함`, `알고있음`, `쉬움`)의 누적 횟수와 비율을 날씨 조화 색상 스택 바와 리스트로 제공.
   - 내부 6단계 히든 기억 등급은 일체 비노출.

### 2.3. 탭 3 · 설정 (`Features/Settings`)
1. **계정 카드**:
   - 프로필 닉네임, 이메일, 인증 제공자(Apple / Google / Email) 배지 및 로그아웃 버튼.
2. **목표 카드**:
   - 현재 목표 JLPT 급수 및 시험일 D-Day 카운트다운.
   - `[목표 급수 · 시험일 재설정]` 버튼을 통해 온보딩 위저드 단계 재실행 가능.
3. **날씨 시뮬레이터 ([`HareruSettingsView`](../Sources/Hareru/Features/Settings/HareruSettingsView.swift))**:
   - 실시간 GPS 위치 날씨 자동 모드 ↔ 수동 기상·시간대 시뮬레이션 모드 전환.
   - 날씨(맑음 / 구름 / 비 / 태풍 / 눈 / 안개 / 폭염) 및 시간대(새벽 / 아침 / 낮 / 노을 / 밤)를 직접 조작하여 전체 앱 테마와 입체 입자 애니메이션 실시간 테스트 가능.
   - '晴れる' 클리어 효과 미리보기 지원.

## 3. 애플 날씨 테마 & 입체 파티클 엔진

### 3.1. 다크/라이트 모드 폐지 & 기상·시간대 주도형 테마
- 인위적인 시스템 다크/라이트 모드 설정을 배제하고, **실제 하늘의 시간대와 날씨가 앱의 유일한 테마**가 됨.
- [`WeatherAtmosphereEngine`](../Sources/Hareru/Services/Weather/WeatherAtmosphereEngine.swift)이 `CoreLocation`과 시각 정보를 기반으로 35가지 조합(5개 시간대 × 7개 기상 조건)의 테마 환경 산출.

### 3.2. 유동적 타이포그래피 대비 ([`WeatherSkyPalette`](../Sources/Hareru/Services/Weather/WeatherAtmosphereEngine.swift))
- 단순한 흑백 대비가 아닌 하늘 색온도에 맞춘 동적 색상 생성:
  - 맑은 정오: 딥 네이비 텍스트 + 크리스탈 글라스.
  - 비 오는 밤: 은은한 웜 슬레이트 화이트 텍스트 + 딥 블루 차콜 글라스.
  - 노을 저녁: 앰버 골드 하이라이트 + 웜 틴트 글라스.
  - 평가 4버튼: 각 기상 테마와 어우러지는 소프트 로즈(`모르겠음`), 앰버 골드(`애매함`), 스카이 애저(`알고있음`), 민트 에메랄드(`쉬움`) 톤 자동 배정.

### 3.3. 60fps 날씨 캔버스 애니메이션 ([`WeatherSkyCanvasView`](../Sources/Hareru/Components/WeatherSkyCanvasView.swift))
- **별빛/햇살**: 밤하늘 반짝이는 별무리, 맑은 낮 부드러운 햇살 광선(Sunbeams).
- **구름/안개**: 바람 속도에 맞춰 완만하게 흘러가는 유기적 클라우드 레이어.
- **비/태풍**: 각도 있는 빗줄기 파티클, 태풍 시 사선 폭우와 간헐적 번개 섬광 효과.
- **눈/폭염**: 부유하는 입체 눈송이, 폭염 시 아른거리는 열기 아지랑이 셰이더.
- **유리창 빗방울 결로 & 흘러내림 ([`CardGlassRaindropOverlay`](../Sources/Hareru/Components/WeatherSkyCanvasView.swift))**:
  - 비/태풍 날씨일 때 카드 표면에 맺히는 물방울 파티클.
  - `정답 보기` 클릭 시 중력 가속도가 적용되어 유리창을 타고 빗방울이 스르륵 흘러내리는 인터랙션 구현.

## 4. FSRS 기억 알고리즘 & 온보딩 진단 시스템

### 4.1. 사용자 관점의 4버튼 & FSRS 6등급 매핑
- 사용자 버튼: **`모르겠음` / `애매함` / `알고있음` / `쉬움`**
- "졸업"이라는 용어는 UI에서 전면 삭제하고 **"외운 단어"**, **"암기 완료"**로 일원화.
- 백그라운드 `ContinuousClock` 반응 시간과 버튼 선택의 조합으로 FSRS 장기 기억 상태(`Stability`, `Difficulty`, `Retrievability`) 산출.

### 4.2. 온보딩 10문항 진단 및 실시간 학습 계획 산출
- **공식 시험일 자동 제안 ([`OfficialJLPTExamSession`](../Sources/Hareru/Models/UserStudyProfile.swift))**:
  - 매년 7월 첫째 일요일, 12월 첫째 일요일을 앱이 자동 계산하여 현시점 가장 가까운 2개 시험 회차를 제안.
- **10문항 진단 테스트 ([`StudyPlanCalculator`](../Sources/Hareru/Models/UserStudyProfile.swift))**:
  - 목표 급수 단어 10장으로 4지선다 테스트 진행.
  - 10문항 결과(정답률 및 평균 응답 속도)를 토대로 초기 기저 지식과 일일 권장 암기량 산출.
- **실시간 학습 동향 반영**:
  - 이후 실제 카드 학습 시 누적되는 반응 시간과 정답률에 따라 남은 시험일까지의 일일 목표와 완주 가능성을 실시간으로 동적 갱신.
