# Hareru (晴れる) — 상세 설계 명세서 (`SPEC.md`)

본 문서는 `Hareru`의 사용자 경험, 게임 시스템, 기억 알고리즘, 데이터 구조, 콘텐츠 생산·배포 및 라이선스 기준 명세서입니다.

---

## 1. 앱 전체 구성 및 검증 순서

### 1.1. 검증 우선순위 (Phase 0.5 → Phase 1)
- **Phase 0.5 (탭 1 실기기 코어 검증)**: 탭 2·3 확장 전 Xcode 앱 타겟(`Hareru.xcodeproj`)으로 **탭 1(10초 그라데이션 카드 + FSRS 순환 큐)**을 먼저 시뮬레이터·실기기에 올려 타이밍 상수([`CardTimingConfig`](../Sources/Hareru/Models/CardTimingConfig.swift))와 손맛을 검증합니다.
- **Phase 1 (3-Tab 순환 루프 완성)**: 검증된 카드 경험을 바탕으로 탭 2(SMS 미션 게임)와 탭 3(통계·성우 도감·처방 노트)을 연결합니다.

### 1.2. 탭 1 — 단어 학습 (`Features/Study`)
- **목표**: 10초 그라데이션 파도 안에서 능동적으로 의미를 떠올리고, `'앎'` 이상 달성 시 당일 세션에서 졸업
- **보상 연결**: 오늘 학습 단어를 일정 개수(기본 5개) 졸업하면 해당 단어의 성우 캐릭터와 플레이할 수 있는 **탭 2 게임(SMS 에피소드) 티켓** 획득

### 1.3. 탭 2 — 게임 그룹 (`Features/Game` · 분기형 SMS 미션 & 미니게임)
게임 카테고리는 향후 다양한 복습 미니게임을 수용하는 독립 모듈로 설계하며, 첫 핵심 모드로 **가상 일본인 SMS 미션 게임**을 탑재합니다.
- **분기형 사전 합성 시나리오 (기계음 제로 & 무서버 동작)**:
  - 실시간 LLM 자유 생성 음성의 불가능성·API 키 노출 문제를 원천 배제하기 위해, 상대 캐릭터의 답장 대사와 보이스(`256kbps` `.m4a`)는 **분기형 시나리오 트리(대성공 / 성공 / 힌트 유도 / 재시도)**로 100% 사전 제작하여 탑재합니다.
  - 3–4턴 단기 스테이지 안에서 오늘 졸업한 단어와 목표 문법(예: `[とりあえず]`, `[ビール]`, `[~ましょう]`)을 조합해 캐릭터의 호감도 게이지를 채웁니다.
- **미션 어휘 한정 한글 발음 매칭기**:
  - 범용 일본어 IME를 구현하는 대신, **해당 미션의 목표 어휘·표현 풀(20–30개)** 안에서 한글 발음 유사도(`칸파이`/`간파이` → `乾杯`, `시마쇼` → `しましょう`, `비루` → `ビール`)를 매칭하여 동음이의어(`乾杯` vs `完敗`) 충돌 없이 즉시 변환을 지원합니다.

### 1.4. 탭 3 — 통계 · 성우 도감 · 처방 노트 (`Features/Insights`)
- **기억 통계**: FSRS 기반 기억 유지율(`R`), 누적 졸업 단어, 다회 실패 후 성공한 역전 단어 기록
- **성우 도감**: 게임 클리어로 친밀도를 올린 캐릭터 프로필 및 추가 에피소드 보관함
- **오프라인 손글씨 처방 노트**: 서로 다른 날 3회 이상 8회 실패 한도에 걸린 난공불락 단어만 모아 종이 노트 필기(한자·예문 3회 쓰기)를 권유하고 완수 시 일반 큐로 복귀

## 2. 카드 인터랙션 & 그라데이션 규칙

### 2.1. 10초 3단 등속 파도 (`Δ6.0s` 일관 속도)
모든 힌트 레이어는 흐림(`0.0`)에서 선명(`1.0`)까지 걸리는 시간(`6.0초`)과 비선형 커브가 동일하며, 시선 흐름(위→아래)에 따라 2초 간격으로 출발합니다. 모든 시간 상수는 `CardTimingConfig` 한 곳에서 관리합니다.

| 요소 | 노출 시점 | 동작 규칙 |
| :--- | :--- | :--- |
| **메인 단어 (`term`)** | `0.0초` (상시) | 카드 등장 즉시 100% 선명 |
| **캐릭터 이름 태그** | `0.0–3.0초` | 음성은 잠긴 상태로 누구의 대사인지만 먼저 암시 |
| **파도 1 · 일본어 예문** | `0.0–6.0초` | 후리가나 없이 한자 실력으로 먼저 읽도록 유도 |
| **파도 2 · 주변 문맥 후리가나** | `2.0–8.0초` | 본문 바로 아래 연한 색으로 표시 (`[한자+뒤 히라가나]` 어절 박스 묶음으로 글자 밀림 차단). **단, 예문 속 표제어(정답 단어) 어절의 후리가나는 발음 스포일러 방지를 위해 정답 보기 전까지 잠금 유지** |
| **파도 3 · 한국어 앞/뒤 문맥** | `4.0–10.0초` | 가운데 정답 조각을 제외한 앞(`before`)·뒤(`after`) 해석 노출 |
| **정답 보호 요소** | **정답 보기 클릭 시 (`0.25초`)** | **단어 발음(`reading`) · 예문 내 정답 어절 후리가나 · 단어 뜻(`meaning`) · 해석 속 정답(`answer`) · 스피커 버튼 2종**은 10초가 지나도 열리지 않으며 클릭 시 `0.25s easeOut`으로 동시 해금 |

### 2.2. 오디오 시퀀스 (`Services/SpeechPlayer`)
1. **사전 제작된 `256kbps` 고음질 오디오 전용 재생**: 기계적인 iOS 기본 TTS 폴백은 사용하지 않으며, 파일 미수신 시에는 재생하지 않음
2. `정답 보기` 클릭 후 **`0.5초` 대기** → 단어 음성 재생
3. 단어 음성 종료 후 **`0.45초` 간격** → 예문 음성 자동 재생
4. 재생 도중 카드를 넘기면 예약된 비동기 `Task`를 즉시 취소하여 오디오 겹침 차단

### 2.3. 실패 침식(`Red+Black`) 및 졸업 정화 연출
- 동일 세션에서 `어려움` 실패가 누적될수록 단어 고유의 3색 배경 그라데이션이 무채색 칠흑(`#0B0B0F`)과 딥 크림슨(`#4A0A12`) 조합으로 단계적 침식
- `4등급(앎)` 이상 달성하는 순간 침식이 걷히며 단어 본연의 퍼스널 컬러로 복원

### 2.4. 한자 2단계 탐색 규칙
- **정답 공개 전 터치 잠금**: 힌트 단계에서 한자 뜻 노출로 인한 스포일러 방지
- **1단계 (말풍선 팝오버)**: 정답 공개 후 단어 내 한자 글자만 개별 터치 가능 → 대표 훈음 및 **현재 단어에서 읽힌 발음 하이라이트** 표시
- **2단계 (한자 상세 시트)**: 말풍선의 `[자세히]` 선택 시 음독·훈독·획수·동일 한자 연관 단어 시트 표시 (아래로 쓸어내려 즉시 카드로 복귀)
- **비한자 단어 예외 처리**: 가타카나 외래어·순수 히라가나 단어는 원어 표기(`Dutch / English: bier / beer` 등) 또는 어원 정보 표시

## 3. FSRS 기억 알고리즘 & 세션 큐 (`Services/SRS`)

### 3.1. 기반 모델: FSRS (`Stability` · `Difficulty` · `Retrievability`)
- 사용자 평가 버튼은 직관적인 4단계(**`어려움` / `애매함` / `앎` / `쉬움`**)를 그대로 유지
- 카드 등장부터 `정답 보기` 클릭까지의 유효 경과 시간을 `ContinuousClock`으로 측정(앱 백그라운드 전환 시 자동 일시정지, `정답 보기` 클릭 순간 고정 잠금)하여 내부적으로 **6단계 히든 등급**으로 세분화

| 내부 등급 | 판정 조건 (반응 시간 × 선택 버튼) | 세션 처리 | FSRS 복습 주기 방향 |
| :--- | :--- | :--- | :--- |
| **1. 어려움** | `어려움` 선택 / `10.0초` 이후 `애매함` 선택 | 앞쪽(`+2장`) 재투입 + 침식도 상승 | 미졸업 (세션 내 재학습) |
| **2. [히든 1 · 힌트의존]** | `6.0–10.0초` 구간 `애매함` / `6.0초` 이후 `앎` 선택 | 세션 말미(맨 뒤) 자력 인출 재확인 | 미졸업 (자력 인출 재검증) |
| **3. 애매함** | `0.0–6.0초` 내 떠올렸으나 확신 부족으로 `애매함` 선택 | 중간 거리(`+4장`) 1회 재확인 | 미졸업 |
| **4. 앎 (졸업 기준선)** | `2.5–6.0초` 적정 시간 `앎` / `7.0초` 이후 `쉬움` 완충 | **컬러 정화 + 졸업(침식 이력 시 최종 확인 1회 후 졸업)** | 표준 초기 주기 (약 1일) |
| **5. [히든 2 · 준-쉬움]** | `0.0–2.5초` 번개 반응 `앎` / `3.5–7.0초` 중반 `쉬움` | **컬러 정화 + 졸업(침식 이력 시 최종 확인 1회 후 졸업)** | 우대 주기 (약 2일) |
| **6. 쉬움** | `0.0–3.5초` 빠른 반응 + `쉬움` 일치 | **컬러 정화 + 졸업(침식 이력 시 최종 확인 1회 후 졸업)** | 장기 점프 (4일 이상) |

### 3.2. 침식 단어 최종 확인 1회 · 상한 캡 난이도 보정 · 8회 캡
- **침식 단어 최종 확인(`Confirmation Lap`) 1회**: 당일 `어려움(1등급)`으로 침식을 겪은 단어는 처음 `4등급` 이상을 받았을 때 컬러는 즉시 정화하되 우연한 1회 정답으로 바로 빠져나가지 않도록 **세션 말미에 최종 확인 1회**를 거친 뒤 연속 통과 시 당일 졸업 처리합니다.
- **Ease Hell 없는 상한 캡 난이도(`D`) 보정**: 당일 다회 실패 시 SM-2처럼 난이도를 무한 가중하지 않고 상한선(`최대 +1.2`, `D ≤ 6.2`) 안에서만 완만하게 초기 난이도를 높여 초반 복습 간격을 촘촘히 잡아준 뒤, FSRS 평균 회귀(`Mean Reversion`)로 자연 복원합니다.
- **원시 이벤트 텔레메트리(`ReviewLogRecord`)**: 추후 반응 시간 경계값과 FSRS 가중치를 실데이터로 최적화할 수 있도록 매 평가마다 `반응 시간`, `버튼`, `히든 등급`, `당일 n번째 노출`, `직전 S·D`, `경과 일수`, `출제 의미 번호`를 기록합니다.
- **당일 8회 조우 캡 & 3일 보류 처방**: 한 세션에서 8번 마주쳐도 졸업하지 못한 단어는 수면 공고화를 위해 내일로 이관하며, 서로 다른 날 3회 누적 보류 시 탭 3 오프라인 손글씨 처방 노트로 자동 분류합니다.

## 4. 다의어 순환 출제 · 콘텐츠 파이프라인 · 라이선스 (`Tools/`)

1. **다의어 1단어 1카드 + 복습 회차별 예문 순환**:
   - 다의어도 카드는 1장으로 유지하되, **초회 학습(`reps == 0`)**에는 **대표 의미(뜻 1)**가 앞면 10초 예문을 담당하고, **복습 회차(`reps >= 1`)**마다 **서브 의미(뜻 2–4)**의 캐릭터 대사 예문이 라운드로빈(`reps % senses.count`)으로 앞면에 출제되어 모든 의미를 자력으로 인출하게 합니다. 정답 공개 시에는 나머지 의미들이 하단에 함께 표시됩니다.
2. **오프라인 자동화 (`Tools/`) 및 호스팅**:
   - LLM 배치 스크립트로 다의어 분리, 캐릭터 대사 예문, 어절 묶음 후리가나, 3색 팔레트, `before/answer/after` 분할 해석 생성 및 무결성 자동 검사
   - 맥북 로컬 `AivisSpeech`(`127.0.0.1:10101`) 합성 후 고음질 `.m4a` 인코딩(기본 `256kbps`, 청취 테스트 기반 모노 비트레이트 프로파일 선택 지원)
   - **Zero-Wait 정적 청크 배포**: 앱 설치 시 전체 텍스트·한자 DB(`~4MB`)와 스타터 오디오를 내장하고, 추가 급수 오디오는 전송료가 없는 **Cloudflare R2 정적 스토리지 + iOS 17+ `URLSession` 백그라운드 다운로드**로 `100단어 청크` 단위 수신 (미수신 시 재생 생략)
3. **데이터 · 음성 라이선스 준수 원칙**:
   - **음성 모델(`AivisHub`)**: 앱스토어 상업 배포가 허용된 **`ACML` 또는 `CC0` 라이선스 모델만 채택**하며, 비상업 제한이 있는 **`ACML-NC` 모델은 원천 배제**합니다.
   - **오픈 사전(`JMdict` · `KANJIDIC2`)**: EDRDG의 `CC BY-SA 4.0` 라이선스에 따라 앱 내 저작자 표시를 명시하고, 사전 원천 어휘·한자 테이블과 자체 창작 대본·연출 데이터를 분리 관리합니다.
