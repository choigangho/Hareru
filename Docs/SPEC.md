# Hareru (晴れる) — 상세 설계 명세서 (`SPEC.md`)

본 문서는 `Hareru`의 사용자 경험, 게임 시스템, 기억 알고리즘, 데이터 구조, 콘텐츠 생산 파이프라인의 기준 명세서입니다.

---

## 1. 앱 전체 구성 (3-Tab 순환 구조)

### 1.1. 탭 1 — 단어 학습 (`Features/Study`)
- **목표**: 10초 그라데이션 파도 안에서 능동적으로 의미를 떠올리고, '앎' 이상 달성 시 당일 세션에서 졸업
- **보상 연결**: 오늘 학습 단어를 일정 개수 졸업하면 해당 단어의 성우 캐릭터와 플레이할 수 있는 **탭 2 게임(SMS 에피소드) 티켓** 획득

### 1.2. 탭 2 — 게임 그룹 (`Features/Game` · SMS 미션 & 미니게임)
게임 카테고리는 향후 다양한 복습 미니게임을 수용하는 독립 모듈로 설계하며, 첫 핵심 모드로 **가상 일본인 SMS 미션 게임**을 탑재합니다.
- **스테이지 규칙**: 무제한 자유 대화가 아닌 **3~4턴 단기 결판 미션제**로 운영하여 AI 토큰 비용을 통제하고 긴장감 유지
- **미션 가이드**: 오늘 졸업한 단어와 목표 문법(예: `[とりあえず]`, `[ビール]`, `[~ましょう]`)을 활용해 상대 캐릭터의 기분(호감도) 게이지를 채우는 방식
- **연출 요소**: 상대방 `'입력 중•••'` 인디케이터, `256kbps` AivisSpeech 음성 메시지 재생, 감정 스탬프, 내 말풍선 하단 1줄 코칭 배지
- **한글 발음 자동 변환 입력기**:
  - 별도의 iOS 일본어 키보드 설정 없이 기본 한글 자판으로 발음을 입력하면 일본어로 즉시 변환 (`칸파이` / `간파이` → `乾杯`, `시마쇼` → `しましょう`, `비루` → `ビール` 유사 발음 보정 포함)

### 1.3. 탭 3 — 통계 · 성우 도감 · 처방 노트 (`Features/Insights`)
- **기억 통계**: FSRS 기반 기억 유지율(`R`), 누적 졸업 단어, 다회 실패 후 성공한 역전 단어 기록
- **성우 도감**: 게임 클리어로 친밀도를 올린 캐릭터 프로필 및 추가 에피소드 보관함
- **오프라인 손글씨 처방 노트**: 서로 다른 날 3회 이상 8회 실패 한도에 걸린 난공불락 단어만 모아 종이 노트 필기(한자·예문 3회 쓰기)를 권유

## 2. 카드 인터랙션 & 그라데이션 규칙

### 2.1. 10초 3단 등속 파도 (`Δ6.0s` 일관 속도)
모든 힌트 레이어는 흐림(`0.0`)에서 선명(`1.0`)까지 걸리는 시간(`6.0초`)과 비선형 커브가 동일하며, 시선 흐름(위→아래)에 따라 2초 간격으로 출발합니다.

| 요소 | 노출 시점 | 동작 규칙 |
| :--- | :--- | :--- |
| **메인 단어 (`term`)** | `0.0초` (상시) | 카드 등장 즉시 100% 선명 |
| **캐릭터 이름 태그** | `0.0 ~ 3.0초` | 음성은 잠긴 상태로 누구의 대사인지만 먼저 암시 |
| **파도 1 · 일본어 예문** | `0.0 ~ 6.0초` | 후리가나 없이 한자 실력으로 먼저 읽도록 유도 |
| **파도 2 · 예문 하단 후리가나** | `2.0 ~ 8.0초` | 본문 바로 아래 연한 색으로 표시 (`[한자+뒤 히라가나]` 어절 박스 묶음으로 글자 밀림 차단) |
| **파도 3 · 한국어 앞/뒤 문맥** | `4.0 ~ 10.0초` | 가운데 정답 조각을 제외한 앞(`transBefore`)·뒤(`transAfter`) 해석 노출 |
| **정답 보호 요소 4종** | **정답 보기 클릭 시 (`0.25초`)** | **단어 발음(`reading`) · 단어 뜻(`meaning`) · 해석 속 정답(`transAnswer`) · 스피커 버튼 2종**은 10초가 지나도 열리지 않으며 클릭 시 `0.25s easeOut`으로 동시 해금 |

### 2.2. 오디오 시퀀스 (`Services/SpeechPlayer`)
1. **사전 제작된 `256kbps` 고음질 오디오 전용 재생**: 기계적인 iOS 기본 TTS 폴백은 사용하지 않으며, 파일 미수신 시에는 재생하지 않음
2. `정답 보기` 클릭 후 **`0.5초` 대기** → 단어 음성 재생
3. 단어 음성 종료 후 **`0.45초` 간격** → 예문 음성 자동 재생
4. 재생 도중 카드를 넘기면 예약된 비동기 `Task`를 즉시 취소하여 오디오 겹침 차단

### 2.3. 실패 침식(`Red+Black`) 및 졸업 정화 연출
- 동일 세션에서 실패가 누적될수록 단어 고유의 3색 배경 그라데이션이 무채색 칠흑(`#0B0B0F`)과 딥 크림슨(`#4A0A12`) 조합으로 단계적 침식
- 4등급(`앎`) 이상으로 졸업하는 순간 침식이 걷히며 단어 본연의 퍼스널 컬러로 복원

### 2.4. 한자 2단계 탐색 규칙
- **정답 공개 전 터치 잠금**: 힌트 단계에서 한자 뜻 노출로 인한 스포일러 방지
- **1단계 (말풍선 팝오버)**: 정답 공개 후 단어 내 한자 글자만 개별 터치 가능 → 대표 훈음 및 **현재 단어에서 읽힌 발음 하이라이트** 표시
- **2단계 (한자 상세 시트)**: 말풍선의 `[자세히]` 선택 시 음독·훈독·획수·동일 한자 연관 단어 시트 표시 (아래로 쓸어내려 즉시 카드로 복귀)
- **비한자 단어 예외 처리**: 가타카나 외래어·순수 히라가나 단어는 원어 표기(`English: beer` 등) 또는 어원 정보 표시

## 3. FSRS 기억 알고리즘 & 세션 큐 (`Services/SRS`)

### 3.1. 기반 모델: FSRS (`Stability` · `Difficulty` · `Retrievability`)
- 사용자 평가 버튼은 직관적인 4단계(**`어려움` / `애매함` / `앎` / `쉬움`**)를 그대로 유지
- 카드 등장부터 `정답 보기` 클릭까지의 경과 시간을 `ContinuousClock`으로 측정하여 내부적으로 **6단계 히든 등급**으로 세분화

| 내부 등급 | 판정 조건 (반응 시간 × 선택 버튼) | 세션 처리 | FSRS 복습 주기 방향 |
| :--- | :--- | :--- | :--- |
| **1. 어려움** | `어려움` 선택 / 10초 이후 `애매함` 선택 | 큐 재투입 + 침식도 상승 | 미졸업 (세션 내 재학습) |
| **2. [히든 1 · 힌트의존]** | 6~10초 구간에서 `애매함` 또는 `앎` 선택 | 세션 말미 가벼운 재확인 | 미졸업 (자력 인출 재검증) |
| **3. 애매함** | 0~6초 내 떠올렸으나 확신 부족으로 `애매함` 선택 | 세션 내 1회 재확인 | 미졸업 |
| **4. 앎 (졸업 기준선)** | 적정 시간 내 `앎` 선택 / 늦은 시간 `쉬움` 완충 | **즉시 졸업 + 컬러 정화** | 표준 초기 주기 (약 1일) |
| **5. [히든 2 · 준-쉬움]** | 0~2.5초 번개 반응 `앎` / 4~7초 중반 `쉬움` | **즉시 졸업 + 컬러 정화** | 우대 주기 (약 2일) |
| **6. 쉬움** | 0~3.5초 빠른 반응 + `쉬움` 일치 | **즉시 졸업 + 컬러 정화** | 장기 점프 (4일 이상) |

### 3.2. 세션 내 실패 면책 (Ease Hell 방지) & 8회 캡
- **당일 실패 면책**: 당일 세션 내 반복 실패는 기억 인출을 위한 예열 과정으로 간주하여 장기 난이도(`D`) 페널티를 부과하지 않음
- **당일 8회 조우 캡**: 한 세션에서 8번 마주쳐도 외워지지 않는 단어는 수면 후 기억 공고화를 위해 당일 세션을 종료하고 내일로 이관
- **누적 3회 보류 처방**: 서로 다른 날 3회 보류 누적 시 탭 3의 오프라인 손글씨 처방 노트로 자동 분류

## 4. 다의어 스키마 & 콘텐츠 생산·배포 (`Tools/`)

1. **1단어 1카드 원칙**: 다의어도 카드는 1장으로 유지하되, **대표 의미(뜻 1)**가 카드의 메인 퍼스널 3색과 앞면 10초 예문을 담당하고 **서브 의미(뜻 2~4)**는 정답 공개 후 각기 다른 성우 캐릭터와 함께 노출
2. **오프라인 자동화 (`Tools/`)**:
   - 오픈 사전(`JMdict`, `KANJIDIC2`) 기반 어휘·한자 매핑
   - LLM 배치 스크립트로 다의어 분리, 캐릭터 대사 예문, 어절 묶음 후리가나, 3색 팔레트, `before/answer/after` 분할 해석 생성 및 무결성 자동 검사
   - 맥북 로컬 `AivisSpeech`(`127.0.0.1:10101`)로 무인 합성 후 **`256kbps` 고음질 `.m4a` 인코딩**(단어+예문 세트당 약 `120~150KB`)
3. **Zero-Wait 배포 구조**:
   - 앱 설치 시 N5~N1 전체 텍스트·한자 DB(`~4MB`) + 급수별 초반 스타터 오디오(256kbps) 기본 내장
   - 사용자가 특정 급수 학습을 시작하면 백그라운드에서 `100단어 청크(~12~15MB)` 단위로 순차 다운로드 (미수신 시에는 재생하지 않음)
