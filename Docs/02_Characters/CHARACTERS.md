## 3. 주임 연구원 (言継 晴)

이름의 읽는 법(名乗り) 설정과 공개 연출은 [SECRETS](../03_Story/SECRETS.md).

### 표기 규칙 (GAME_DESIGN §2.1)

> ✅ **결정 (2026-11-01)**: 화면·대사·음성 라벨에서 '가이드'라는 말은 쓰지 않고 **직함 「주임 연구원 (主任研究員)」** 으로만 표기. 안내 역할은 설정이 아니라 연출로 보여 줌. 내부 식별자(`guide_researcher` 등)는 데이터 호환을 위해 유지.

### 역할 — 연구소의 안내자 (GAME_DESIGN §6)

- 카이로소프트의 비서처럼 **모든 시스템의 첫 안내와 피드백**을 담당.
- 학습 탭과의 연결: 학습 카드 상단의 안내 문구(보류 1번)를 이 연구원의 짧은 코멘트로 대체할 수 있음.
  - 예: 어려운 단어를 '알고있음'으로 넘기면 「えっ、それ知ってるんですか!? さすが…」
- 연구원 상태: 기분/피로도, 연구소 단계에 따른 의상·책상 변화, 호감도에 따른 개인 에피소드.
- 진엔딩: N1 달성 → 연구원이 '최후의 1인'이 아니게 됨 (주인공이 두 번째 계승자) → 연구소 위 완전한 晴れ.

## 4. 미오 — 폐교의 유령 (TOWN_DRAFT §4)

- 폐교 안에 혼자 있는 수수께끼의 소녀. "옛날엔 이런 것도 있었대요" 하며 안내하고 **직접 읽기도 함** (주인공에게만 들림).
- **그냥 유령** (서버 · 기억 데이터 같은 SF 설명 없음). 폐교는 2079년 이전의 평범한 학교.
- 《식스 센스》 규칙: 사람 많은 곳엔 안 감(폐교 + 가끔 연구소) · 주임 연구원 · KURO는 미오에게 반응하지 않음 · 미오와의 대화는 늘 주인공과 둘만 · 다른 인물은 미오 이야기를 하지 않음.
- **정체 공개**: N2쯤 폐교의 2079년 졸업 앨범에서 미오의 사진 발견 (N1 최종장은 주임 연구원 이야기 몫).
