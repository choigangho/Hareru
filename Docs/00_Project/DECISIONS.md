# 결정 기록

> 상태: **확정** (2026-11-04)
> 원본 여부: 소유자 결정의 목차는 이 파일. 결정의 자세한 내용은 '자세한 문서' 칸이 원본.
> 관련: [ROADMAP §2](ROADMAP.md) · [04_Design/README](../04_Design/README.md)

## 결정 규칙

- **최신 결정이 이긴다.** 옛 결정은 반박되지 않으면 계속 유효하다.
- 애매하면 소유자에게 묻는다.
- 바뀐 결정은 지우지 않고 **'대체됨 → #번호'** 로 표시한다.
- 새 결정은 맨 아래 표에 한 줄씩 추가한다.
