## 1. 개요 및 인계 배경

사용자님께서 **주 작업 공간을 클로드 코드(Opus 5.5)로 전환**하고, **안티그래비티(Argon)를 아키텍처 감리, 버그 디버깅, 테스트 스위트 검증 전담**으로 운영하기로 결정하셨습니다.

클로드 코드가 작업하는 과정에서 19개 요구사항 중 **자잘자잘하게 빠지거나 불일치했던 지점들**을 정밀 감사(Forensic Audit)하고, 안티그래비티에서 진행했던 작업부터 클로드 코드의 작업분까지 명확한 기준선을 확정하여 인계합니다.

## 3. 클로드 코드(Opus) 작업 감사: 누락 및 보완 필요 사항 (자잘한 디테일)

오퍼스가 전반적인 뷰 형태는 빠르게 잡았으나, 실제 사용자 시나리오에서 **놓치거나 어색하게 방치된 5가지 디테일**을 발견하고 정리했습니다.

### ① `words.json` 시드 데이터 부족으로 인한 N1~N2 진단 오류 ⚠️
- **현상**: 현재 `words.json` 카탈로그는 총 30단어(N5: 11개, N4: 11개, N3: 7개, N2: 1개, N1: 0개)로 구성되어 있습니다.
- **영향**: 사용자가 온보딩에서 "N2 준비"를 선택했을 때 10문항 진단 테스트를 출제하려면 N2 단어가 최소 10개 이상 있어야 하지만, 1개뿐이어서 알고리즘이 N3/N4/N5 단어를 빌려와서 출제합니다. N1의 경우 100% 타 급수 단어로 출제됩니다.
- **클로드 코드 할 일**: `words.json`에 N1~N2 고빈도 표제어 및 예문 데이터를 각 10~20개씩 보충 필요.

### ② 설정에서 '목표 재설정' 클릭 시 로그인 화면부터 뜨는 UX 결함 🛠️ (Argon에서 즉시 수정 완료)
- **현상**: 설정 탭에서 `[목표 급수 · 시험일 재설정]`을 누르면 `OnboardingFlowView`가 호출되는데, 기존 프로필이 있음에도 `Step 1 (계정 가입/로그인)`부터 열려 닉네임과 비밀번호를 다시 입력해야 하는 어색함이 있었습니다.
- **조치 (커밋 `98a9dc6`)**: `OnboardingFlowView`에 `initialStep` 매개변수를 추가하고, 기존 프로필이 있는 상태에서 호출 시 `Step 2 (목표 급수/시험일 선택)`로 바로 이동하도록 수정 완료.

### ③ 설계 문서(`SPEC.md`, `Blueprint.canvas`) 방치 🛠️ (Argon에서 즉시 수정 완료)
- **현상**: 코드는 3탭(학습/통계/설정)과 날씨 글라스 UI로 완전히 전환되었으나, `Docs/SPEC.md`는 여전히 레거시 탭 2(SMS 게임), 처방 노트, 성우 도감, 구버전 버튼 명칭(`어려움/애매함/앎/쉬움`)으로 남아 있었습니다.
- **조치 (커밋 `98a9dc6`)**: `Docs/SPEC.md`를 5개 섹션의 최신 명세서로 전면 재작성하여 코드와 100% 일치시켰고, 사용자님이 편집하신 `Blueprint.canvas`도 포맷팅을 맞춰 커밋 완료.

### ④ FSRS 반응 시간 임계치(6초)와 무힌트 예문의 체감 난이도 불일치 조율 필요 💡
- **현상**: 사용자 요구사항에 따라 카드 앞면에서 후리가나와 한국어 해석을 완전히 제거했습니다. 이에 따라 한자 문장을 읽는 데 자연스럽게 시간이 더 소요됩니다.
- **주의점**: 현재 `FSRSEngine.classifyGrade`는 6.0초(`standardGoodUpperBound`)를 넘어서 `알고있음`을 누르면 내부 등급이 `hiddenHintAssisted`(2등급, 미졸업)로 강등되어 카드가 큐 맨 뒤로 재투입됩니다. 사용자는 "알고 있어서 눌렀는데 왜 또 나오지?"라고 느낄 수 있습니다.
- **클로드 코드 할 일**: `CardTimingConfig`의 `standardGoodUpperBound`를 순수 예문 독해 시간을 감안해 7.5~8.0초 수준으로 상향하거나 사용자 피드백을 수렴할 것.

### ⑤ 레거시 게임 모듈 분리 정리 📦
- **현상**: `Sources/Hareru/Features/Game/` 및 `Services/Game/`에 SMS 게임 뷰와 변환기 코드가 남아 있으나 메인 탭에서는 링크가 끊겨 있습니다.
- **권장 방향**: 삭제하지 않고 실험용 독립 모듈(`Modules/GameExperiment`)로 남겨두어 추후 게임을 완전히 갈아엎을 때 재활용할 수 있게 유지.
