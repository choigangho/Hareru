## 0. 한 줄 요약

학습 챕터는 **판독 단말**이라는 기기다. 화면 문구마다 카탈로그 단어를 하나씩 붙여 두고, 사용자가 그 단어를 익히면 문구가 일본어로 **복원**된다. N1 단어인 `設定`(설정)이 가장 마지막에 바뀌어, 단말 전체가 일본어가 되는 것이 엔딩 연출이 된다.

## 2. 전환 규칙

### 2.1 기준 (FSRS, 히스테리시스)

| 상태 | 들어가는 조건 | 나오는 조건 |
| :--- | :--- | :--- |
| 한글 → **일본어** | 안정도 S ≥ **21일** 이고 현재 기억 확률 R ≥ 0.90 | — |
| 일본어 → **한글** | — | S < **14일** 이거나 R < 0.75 |

- 21일과 14일 사이, R 0.90과 0.75 사이는 **지금 상태를 유지**하는 여유 구간. 경계에서 깜빡이지 않음.
- R은 마지막 복습 뒤 시간이 흐르면 내려가므로, 오래 쉬면 복습 없이도 자연스럽게 한글로 돌아감.
- **언제 다시 계산하나**: 앱이 앞으로 나올 때와 세션이 끝날 때만. 카드를 넘기는 중에는 문구가 바뀌지 않음.

### 2.2 연출

| 순간 | 연출 |
| :--- | :--- |
| 처음 일본어로 바뀔 때 (단어마다 한 번) | 픽셀 모자이크 → 글자 디코딩(0.6초) + 후리가나가 3초 동안 떠 있음 + 작은 효과음 |
| 다시 일본어로 바뀔 때 (두 번째부터) | 짧은 크로스페이드만, 후리가나 없음 |
| 한글로 돌아갈 때 | 글자가 0.4초 동안 흐려지며(노이즈) 한글로 바뀜. 꾸짖는 느낌은 주지 않음 |
| '동작 줄이기' 켜짐 | 모든 연출 없이 바로 바뀜 |
| 시험 대비 집중 모드 (STORY_BIBLE §4.3) | 전환은 그대로, 연출만 생략 |

### 2.3 접근성 · 끄기

- **길게 누르면** 한글 원문을 말풍선으로 보여 줌.
- **VoiceOver**는 늘 한국어로 읽음 (`accessibilityLabel`은 한글로 고정).
- **설정 > 표시 언어 고정** 스위치를 켜면 모두 한글로 고정. 이 스위치의 문구 자체는 전환하지 않음.
- 평가 버튼 · 정답 보기처럼 **잘못 누르면 학습 기록이 틀어지는 버튼**은 전환 대상에서 뺌.

### 2.4 예외 처리

| 경우 | 처리 |
| :--- | :--- |
| 연결할 단어가 카탈로그에 없음 (`答え` · `研究所` · `ログアウト`) | 한글로 유지. 빌드 검사가 이런 문구를 목록으로 알려 줌 |
| 단어는 있지만 사용자가 아직 그 급수 전임 | 그냥 한글. 급수가 오르면 자연스럽게 열림 |
| 합성어 문구 (`研究所`) | 안 1: 구성 단어(研究)만 기준으로 삼고 표시만 `研究所`. 안 2: 한글 유지. 오너 결정 (§5) |
| 같은 표제어가 여러 급수에 있음 (`今日` N5 · N3) | 가장 낮은 급수의 단어 id를 씀 |
| 활용형 (`覚える` → `覚えた`) | 표시는 카탈로그 표제어 그대로 (사전형). 활용형 허용 여부는 오너 결정 |

## 3. 구현 스케치

```
UILexiconEntry          문구 키 · 한글 · 세계관 이름 · 단어 id · 표기 · 읽기 (정적 표, JSON 리소스)
UILexiconRevealState    키별 { 일본어 표시 여부, 처음 바뀐 시각 }  ← 화면 상태, FSRS 기록 아님
LexiconRevealService    @Observable. 기록을 읽어 상태를 계산하고 label(for:)을 돌려줌
LexiconText(key:)       화면용 뷰. 연출 · 후리가나 · 길게 누르기 · VoiceOver 처리
```

| 무엇을 | 어디서 |
| :--- | :--- |
| 안정도 S | `MemoryStoreProtocol.allSnapshots()` → `WordMemorySnapshot.stability` |
| 현재 기억 확률 R | `FSRSEngine.retrievability(elapsedDays:stability:)` (`lastReviewedAt` 기준) |
| 단어 존재 · 표기 · 읽기 | `CatalogRepository.word(forId:)` |
| 전환 상태 저장 | `UILexiconRevealState`를 별도 저장 (UserDefaults 또는 작은 SwiftData 레코드) |
| 끄기 스위치 | 사용자 설정에 `isLexiconRevealEnabled` 하나 추가 |

- **GAME_DESIGN §4.1 원칙**: 이 서비스는 `WordMemorySnapshot` · `ReviewLogEntry`를 **읽기만** 함. 저장소에 쓰는 메서드(`saveSnapshot` · `appendReviewLog`)는 아예 넘기지 않고, 읽기 전용 프로토콜(`allSnapshots`만 있음)로 감싸 전달.
- 전환 판정은 순수 함수 `LexiconRevealRule.next(current:stability:retrievability:)` 하나로 두고 단위 테스트로 히스테리시스를 고정.
- 빌드 검사(테스트): 표의 모든 단어 id가 카탈로그에 있는지, 같은 키가 두 번 나오지 않는지, 평가 버튼 키가 표에 없는지.
- 현재 번들 `words.json`은 30단어뿐 (BACKLOG 6번). 전환 기능은 전체 카탈로그가 번들된 뒤에 의미가 있음.

## 5. 오너가 정할 것

1. **기기 이름**: 판독기 / 해독 단말 / 復元端末. 통계는 판독 기록 / 연구 일지.
2. **통계 탭 단어**: 統計 (N2, 늦게 바뀜) / 記録 (N3).
3. **기준 수치**: S 21일 · 14일, R 0.90 · 0.75 그대로 갈지.
4. **합성어 · 활용형**: `研究所` · `覚えた`처럼 카탈로그 표제어와 다른 표기를 허용할지.
5. **처음 바뀔 때 알림**: 화면 안 연출만 / 주임 연구원이나 KURO가 한마디 (집중 모드에서는 생략).
6. **엔딩**: `設定`이 바뀌는 순간에 특별 연출(STORY_BIBLE §6과 연결)을 둘지.
7. **픽셀 글꼴**: 후보 선정과 라이선스 (한글 + 일본어를 모두 지원하는 픽셀 글꼴은 드묾).
