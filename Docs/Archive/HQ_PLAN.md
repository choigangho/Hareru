## 2. 팩에서 그대로 쓸 것 (다시 칠해서)

팩 소품은 아이소 기기라 **화면 머리 그림 · 빈 화면 그림**으로 씀 (평면 UI 틀은 직접 그림). 주황 → 청록으로 다시 칠함.

| 화면 | 팩 소품 (애니 있음) | 쓰임 |
| :--- | :--- | :--- |
| 통계 머리 | `desk_pc` (모니터 2대에 코드 · 차트가 흐름) | ✅ 시안에 넣음 |
| 학습 머리 | `wall_screen` 또는 `workbench` | 판독 단말 작업대 |
| 설정 › 계정 · 동기화 | `network_cabinet` · `server_rack_open` | 깜빡이는 랙 |
| 설정 › 목표(시험일 D-day) | `wall_clock` | 시계가 돌아감 |
| 설정 › 날씨 | `ac_unit` | 팬이 돎 |
| 설정 › 위치 권한 | `wall_camera` | 카메라 LED |
| 빈 화면 · 로딩 | `printer_3d` · `robot_arm` | 작업 중 연출 |

## 3. 제작 목록 (오너 확인 후)

**공통** — 판 ✅ · 작은 판 ✅ · 버튼 3상태(LED 포함) · 큰 주 버튼(호박) · 칩 · 입력란 · 구분선 · 토스트 · 모달 · 스크롤 표시
**탭바** — 몸체 · 아이콘 4종 살아 있는 버전(단말 화면 글줄 흐름 · 연구소 창 불빛 · 기록 막대 출렁 · 설정 톱니 한 칸 회전) · 강조 링(있음)
**학습** — 대시보드 판 · D-day 계수기(숫자 넘김) · 시작 버튼 · 진행 헤더 · 단어 카드 틀 · 정답 보기 버튼 · 평가 버튼 4(신호 막대 살아 있음) · 음성 버튼(소리 파동) · 세션 완료 화면
**통계** — 잔디 5단계 + 오늘 칸 ✅ · 숫자 아이콘 4 ✅ · 평가 막대 ✅ · 날짜 말풍선
**설정** — 계정 카드(아바타 틀) · 목표 카드 · 토글(LED) · 세그먼트 · 슬라이더 · 권한 버튼 · 섹션 머리 그림(위 표)
**미룸** — 날씨 아이콘 22종(다음 차례) · 글꼴(오너 결정) · 모자이크 · 글리치(코드)
