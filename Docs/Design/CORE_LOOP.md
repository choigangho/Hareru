## 0. 한 줄

**출근해서, 사람과 말하고, 책상에 앉아 문서를 판독하고, 퇴근한다.** 판독(= 실제 학습)이 세계를 움직이는 유일한 행위이고, 대화는 그 결과를 보여 주고 다음 판독으로 이끈다.

원칙 (GAME_DESIGN §3 · §4.1 유지):
1. 자원 · 진행을 **버는 행위는 판독뿐**. 대화 · 탐색은 쓰거나 보는 일.
2. 게임은 FSRS 기록을 **읽기만** 한다. 연출이 기록을 고치지 않는다.
3. 장면 하나는 1~3분. 판독을 오래 막지 않는다 (N5_SCRIPT §0.1).

## 1. 하루 흐름

```
 ┌─ 출근 ──────────────┐   문 → 연구소 단면. 오늘 조건으로 장면 대기열을 만든다
 │                     │
 ├─ 대화 (앞) ─────────┤   조건이 맞은 장면 0~2개 (D1 · D2 · R2 · R4 …)
 │                     │
 ├─ 판독 ──────────────┤   책상에 앉음 → 오늘 문서 더미 (복습 → 새 단어)
 │    ↕ 카드 이벤트       │   0~2단계 이벤트는 판독 안에서, 멈추지 않음
 ├─ 대화 (뒤) ─────────┤   판독 중 조건이 찬 장면 (B1~B3 등) — 사이클 끝난 뒤
 │                     │
 └─ 퇴근 ──────────────┘   밤 연구소 · 저장 · 내일 예고 한 줄
```

| 단계 | 장소 (화면) | 무엇이 일어나나 | 끝나는 조건 |
| :--- | :--- | :--- | :--- |
| **출근** | 연구소 단면 (낮) | 출근 기록(잔디 한 칸). 대기 장면 계산. B1 이후엔 KURO 한 줄 보고 (`오늘 복습 {n}건`) | 자동 → 대화 또는 자유 행동 |
| **대화 (앞)** | 단면 위 대사창 | 그날 조건이 맞은 장면. 없으면 생략 | 장면 끝 |
| **자유 행동** | 연구소 단면 | 물건 · 사람을 눌러 짧은 반응, 기록 · 단말 설정 열기. 책상이 늘 빛남 (다음 할 일) | 책상을 누름 |
| **판독** | 책상 확대 (판독 장면) | 오늘 문서 더미를 처리 (§2). 일어서기(Esc)로 언제든 중단 · 재개 | 더미가 빔, 또는 일어섬 |
| **대화 (뒤)** | 단면 / 해당 장소 | 판독 중 조건이 찬 장면 (첫 `업무` 단어 → B1 등) | 장면 끝 |
| **퇴근** | 단면 (밤) | 주임 한 줄 · 저장 · 내일 복습 예상 수 | 문을 나섬 → 오늘 종료 화면 |

- **퇴근은 강요하지 않는다.** 더미를 다 비우지 않고 문을 나서도 된다 (주임 한 줄 "남은 건 내일 같이 봐요"). 다만 스토리 튜토리얼(D1 T-7 과제)처럼 대본이 판독을 요구하는 구간은 그 문서를 끝내야 장면이 넘어간다.
- **퇴근 뒤 다시 켜면**: 같은 날이면 밤 연구소에서 이어서 판독 가능 (추가 판독은 그날 대기열 남은 것만). 날이 바뀌었으면 출근부터 (→ PROGRESSION §1).
- **집중 모드**: 출근 · 대화 · 퇴근 장면을 건너뛰고 곧장 판독 장면으로. 일어난 장면은 미확인 기록 보관함으로 (STORY_BIBLE §4.3). 해금은 그대로 일어남.

### 1.1 탭 → 장소 (다이제틱 전환)

SwiftUI 앱의 탭 4개(학습 · 연구소 · 통계 · 설정)는 Godot에서 **연구소 안의 물건**이 된다. 탭 바 · 독은 없다.

| 예전 탭 | Godot에서 | 여는 법 |
| :--- | :--- | :--- |
| 학습 | **판독 장면** — 신입 책상의 自炊式 判読機 | 단면에서 신입 책상을 누름 / 단축키 |
| 연구소 | **연구소 단면** (기본 화면) | 판독 장면에서 일어서기 (Esc) |
| 통계 | **기록** — 벽에 걸린 출근부 · 업무일지 클립보드 | 단면에서 클립보드를 누름 |
| 설정 | **단말 설정** — 벽 배전반 (스위치 · 다이얼) | 단면에서 배전반을 누름 |

> **확정 C-1** (2026-11-03) — 탭 이동 방식. **확정: 위 표처럼 단면 속 물건을 눌러 이동** (+ 키보드 단축키 1~4). 소유자 시안 v3(사다리꼴 원근 콘솔 위의 물리 버튼 4개)은 "탭 바를 물건으로 바꾼 것"이라 화면 아래에 상시 콘솔이 남는다. 스파이크(단면 → 책상 확대)가 콘솔 없이 더 다이제틱했으므로 콘솔은 빼는 쪽을 추천. 시안 M-2에서 둘을 비교.

## 2. 판독 1장 안의 흐름

스파이크(`reader.gd`)에서 검증한 흐름을 그대로 확정한다.

```
더미에서 한 장 → 판독기에 끼움 → [시계 시작]
   헤드 4회 통과 (10초) — 예문이 단계적으로 드러남
→ 손잡이 당김 = 판독 [시계 멈춤 = 반응 시간]
   헤드 1회 빠르게 → 후리가나 · 뜻 · 번역 · 음성
→ 앞면 키 4개 중 하나 → 6단계 숨은 등급
→ 도장(判読 / 再) → 처리함 또는 더미로
```

| # | 단계 | 화면 (물건) | 입력 | 세부 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | 끼움 | 왼쪽 문서 더미 → 판독기 판 위 | — | 0.45초. 끼움이 **끝난 순간** 시계 시작 (`shown_at`) |
| 2 | 앞면 | 표제어(후리가나 없음) + 예문(모자이크) | — | 표제어는 처음부터 보임. 뜻 · 번역 · 음성 없음 |
| 3 | 스캔 | 판독 헤드가 종이 위를 **4회** 지나감, 10초 | — | 선명도 0.12 → 0.35 → 0.60 → 0.85 → 1.0. 갱신 시점 ≈ 0.7 · 3.2 · 5.7 · 8.2초. 10초 뒤엔 예문 완전 선명, 헤드 정지 |
| 4 | 판독 | 큰 손잡이 | 클릭 · 드래그 / `Space` `Enter` | 당긴 순간 **반응 시간 확정**. 헤드 1회 빠르게 → 표제어 · 예문에 후리가나, 뜻, 번역(정답 부분 밑줄), 담당 인물 이름표 `声 · 겐` |
| 5 | 음성 | 판독기 스피커 | `R` 다시 듣기 | 표제어 음성 → 예문 음성. 판독 **전에는 재생하지 않음** (정답 노출). 담당 인물을 아직 못 만났으면 주인공 목소리 (PROGRESSION §2) |
| 6 | 평가 | 앞면 실물 키 4개 (판독 후에만 불이 들어옴) | 클릭 / `1` `2` `3` `4` | 모르겠음 · 애매함 · 알고있음 · 쉬움 |
| 7 | 도장 | `判読`(졸업) / `再`(다시) | — | 졸업 → 오른쪽 처리함. 다시 → 왼쪽 더미에 다시 꽂힘 |
| 8 | 다음 | 더미 높이가 줄어듦 = 남은 장수 | — | 더미가 비면 주임 CRT "오늘 문서는 끝났어요" |

### 2.1 반응 시간 × 4버튼 → 6단계 숨은 등급 (변경 없음)

`GodotSpike/scripts/fsrs.gd` `classify()` = Swift `FSRSEngine` 그대로. **이 규칙은 P1에서 바꾸지 않는다** (소유자 우선순위 1번).

| 키 \ 반응 시간 | < 2.5초 | 2.5 ~ 3.5 | 3.5 ~ 6 | 6 ~ 7 | 7 ~ 10 | ≥ 10 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **1 모르겠음** | 1 AGAIN | 1 | 1 | 1 | 1 | 1 |
| **2 애매함** | 3 HARD | 3 | 3 | 2 HINT | 2 | 1 AGAIN |
| **3 알고있음** | 5 NEAR_EASY | 4 GOOD | 4 | 2 HINT | 2 | 2 |
| **4 쉬움** | 6 EASY | 6 | 5 NEAR_EASY | 5 | 4 GOOD | 4 |

| 숨은 등급 | 오늘 대기열에서 | FSRS |
| :--- | :--- | :--- |
| 1 AGAIN | **2장 뒤**에 다시 끼움, 실패 +1 | 기록 안 함 (졸업 때 반영) |
| 3 HARD | **4장 뒤**에 다시, 실패 +1 | 기록 안 함 |
| 2 HINT_ASSISTED | **맨 뒤**로 | 기록 안 함 |
| 4 GOOD · 5 NEAR_EASY · 6 EASY | **졸업** — 처리함으로 | `graduate()`로 S · D · due 갱신. 최소 간격 1 · 2 · 4일 |

- 졸업 때 오늘 실패가 있었고 이전 기록이 있으면 **lapse**(잊었다 다시 외움)로 처리 → S를 재학습 공식으로.
- 스캔 단계와 등급 경계가 맞물림: 6초(≈ 3번째 스캔 직후)와 10초(스캔 끝)가 힌트 경계 — "예문 문맥 도움을 받았는가"를 반응 시간으로 판정하는 장치. BACKLOG 7(6초 임계치 재검토)은 그대로 보류.

### 2.2 대기열 규칙

| 규칙 | 값 | 출처 |
| :--- | :--- | :--- |
| 순서 | 복습(due ≤ 오늘) 먼저 → 새 단어 | 스파이크 |
| 새 단어 한도 | 하루 **20개** (D1은 튜토리얼 5 + 과제 15 = 20) | 스파이크 · N5_SCRIPT |
| 새 단어 묶음 | **대분류별로 묶어서** 나옴 (하루 학습 = 장소 방문) | TOWN_DRAFT §2 |
| 복습 묶음 | 묶지 않음, due 순서 | TOWN_DRAFT §2 |
| 같은 단어 하루 상한 | **8회** 노출 후엔 그날 대기열에서 빼고 내일 첫 장으로 | GAME_DESIGN §4.1 (스파이크엔 없음 — P2에서 추가) |
| 다의어 | 복습 회차마다 뜻을 돌아가며 (`reps % senses`) | 스파이크 |
| 중단 | 일어서면 지금 문서는 **판독 전이면 더미 맨 위로 되돌림, 시계 무효**. 판독 후 평가 전이면 평가부터 | 새 규칙 (반응 시간 오염 방지) |
| 창 포커스 잃음 | 판독 전이면 시계 일시정지 + 스캔 정지, 돌아오면 그 문서를 **처음부터 다시** | 새 규칙 |

### 2.3 판독 중 카드 이벤트 (N5_SCRIPT §1 → 물건으로)

| 단계 | 예전 (카드) | Godot (문서 · 판독기) |
| :---: | :--- | :--- |
| 0 살아나는 문서 | 카드 위 빗방울 · 고양이 | 종이 위로 같은 연출 (雨: 종이에 빗방울 자국, 猫: 책상 위를 고양이가 지나감) |
| 1 글자가 번지는 문서 | 「정답 보기」 → 「見る」 | 손잡이 명판 「判読」 → 「見る」, 처리함 명판 → 「出る」 등 **판독기 부품의 명판**이 바뀜 |
| 2 말 거는 문서 | 카드 위로 초상 | 오른쪽 **주임 CRT**(또는 그 인물의 초상)가 한두 마디. 판독은 멈추지 않음 |
| 3 멈추는 문서 | 학습 정지 (N3 諦める) | 판독기 헤드가 걸리고 손잡이가 안 내려감. N5엔 없음 |

### 2.4 판독이 만드는 결과 (보상)

- **연구 포인트** (화면 표시 「연구 포인트」, 대사 · 단말 표기는 「研究ポイント(けんきゅうポイント)」도 가능): 졸업한 문서 수와 S 증가분으로 계산 (GAME_DESIGN §4.1 규칙 그대로: 같은 날 같은 단어 1회, 4등급 이상만). 연구소 벽의 **연구 장부**(넘김 숫자판)에 쌓임. D1에서는 누수 수리(5)와 스탠드(과제 보상)에만 씀.
- **잔디 · 기억 안정도**: 기록 클립보드에 반영.
- **말**: 졸업한 단어는 대사에서 『』 강조로 들림 (SPEECH_DECAY §2).

> **확정 C-2** (2026-11-03) — 연구 포인트를 Godot에서도 유지할지. **확정: 유지하되 N5 동안은 '대본이 정한 수리 · 확장'에만 쓰는 단일 자원**으로. 예산 · 영향력 · 시설 자유 배치(카이로소프트식 경영)는 P3에서 다시 결정 (BACKLOG 추가). D1 대본(T-3 누수 수리, T-7 스탠드)이 연구 포인트를 쓰므로 완전히 빼면 대본을 고쳐야 함.

## 3. 대화 흐름

| 요소 | 규칙 |
| :--- | :--- |
| 장면 트리거 | 장소 진입 · 판독 사이클 종료 · 날짜 · 조건(PROGRESSION §1.3). 판독 **도중**에는 2단계 '말 거는 문서'만 |
| 대사 진행 | 클릭 / `Space`: 타자 중이면 끝까지 → 다음 줄. 자동 진행 없음 (기본) |
| 일본어 줄 | 음성 재생 + 일본어(후리가나) 표시, 한국어 뜻은 **줄을 누르거나 `Tab`** 으로 (lines 규칙). 외운 단어는 『』 강조 → 그 단어를 누르면 뜻 (마우스 오버 전용 기능 없음 — ART_STYLE_SHEET §9) |
| 표정 | 줄마다 초상 교체. `확대` 태그는 같은 초상을 정수배 확대 |
| 선택지 | 키캡 버튼 2~3개, `1` `2` `3` |
| 입력 | 이름 입력 (D1 T-1) — 타자기 종이에 쓰는 형태 |
| 건너뛰기 | 장면 단위 건너뛰기 (`Esc` 길게 누르기). 건너뛴 장면은 보관함에서 다시 볼 수 있음 |
| 기록 | 본 장면 ID를 저장 (재생 방지 · 보관함) |
