## 1. 날짜

### 1.1 하루의 경계

- 게임 날짜 = **실제 날짜** (GAME_DESIGN §5.5). 연도는 2094로 표시, 월 · 일 · 요일은 실제.
- 하루가 바뀌는 시각 = **새벽 4시** (현지 시각).
  - 이유: N5_SCRIPT R3 '심야 접속 (0~4시)'은 "자기 전 늦게 켠 밤"이라 전날에 속해야 한다. 자정 경계면 밤 11시 D1 → 새벽 1시 D2가 바로 열려 버림.
  - FSRS 복습일(`start_of_day_after`)도 같은 4시 경계로 맞춘다 → "오늘 복습할 것"과 "오늘 출근"의 날이 항상 같음. (스파이크는 자정 기준 — P2에서 바꿈.)

> **확정 P-1** (2026-11-03) — 하루 경계 4시. FSRS due 계산 기준도 4시로 옮기면 Swift 앱과 복습일이 최대 4시간 다르다 (Swift 앱은 동결 · 보관 예정이라 문제 적음). **확정: 4시로 통일.**

### 1.2 출근일이 넘어가는 조건

| 규칙 | 내용 |
| :--- | :--- |
| 새 출근일 | 날짜(4시 경계)가 바뀐 뒤 처음 켤 때, **그리고 직전 출근일의 대본 장면이 끝났을 때** |
| 하루 대본을 못 끝냄 | 예: D1 도중 꺼짐 → 다음 날 켜도 **D1을 이어서** (건너뛰지 않음). 다만 그날 복습 대기열은 오늘 날짜로 새로 계산 |
| 쉬는 날 | 쉰 날은 세지 않음. 출근일 번호 = 실제로 출근한 날 수. 3일 이상 쉬면 복귀 날 R4 장면 |
| 하루 두 번 | 같은 날 다시 켜면 같은 출근일 (출근 장면 생략, 바로 연구소) |
| 시계 조작 | 시스템 시계를 뒤로 돌리면 날짜가 줄어들지 않게 '가장 늦게 본 날짜'를 저장해 그보다 앞으로 가지 않음 |

### 1.3 장면은 날짜가 아니라 조건으로 열림

N5_SCRIPT §2 그대로. 출근일 번호로 열리는 건 D1 · D2뿐이고, 나머지는 판독 조건.

| 장면 | 조건 | 슬라이스 |
| :--- | :--- | :---: |
| D1 | 첫 실행 | ✅ |
| D2 | 출근일 2 | — |
| B1 KURO | `업무` 대분류 단어를 처음 판독 (졸업 아니어도 처음 **보는** 순간 B1-0, 사이클 뒤 B1-1~) | — |
| B2 겐 | `생활` 처음 | — |
| B3 미오 | `교육` 처음 | — |
| R1 | 처음 '모르겠음' 3연속 | — |
| R2 | 연속 출근 7일 | — |
| R3 | 처음 0~4시 접속 | — |
| R4 | 3일 이상 쉬고 복귀 | — |

- **'안다'의 정의** (M1~M3 · 승급 조건 공통): FSRS 기록이 있고 **지금 R ≥ 0.90**인 단어 (= 말 잃기 '선명' 상태). 잊으면 숫자도 줄어든다 → 말 잃기와 같은 기준.
- 하루에 열리는 장면 수 제한: **판독 앞 1개 + 뒤 2개**까지. 넘치면 다음 출근일로 미룸 (Beat가 한꺼번에 몰려 판독을 막지 않게). B1~B3는 R보다 우선.

## 2. 인물 · 목소리 해금 — 만나야 열린다

GAME_DESIGN §12.2 · TOWN_DRAFT §3 그대로 (STORY_BIBLE과 충돌 없음).

| 규칙 | 내용 |
| :--- | :--- |
| 단어의 담당 인물 | 단어의 **대분류**가 정함 (급수와 무관). 분야 없음 → 주인공(직접 하는 말) / 주임(설명하는 말) |
| 만남 | 그 인물의 첫 만남 장면(B1 · B2 · B3 …)을 **끝까지 본 순간** `met_characters`에 추가. 집중 모드면 장면 없이 조건 충족 순간 추가 |
| 만나기 전 | 그 인물 담당 단어는 **주인공 목소리**로 재생 (선택한 남성 목소리 3종 중 하나) |
| 만난 뒤 | 그 인물 목소리로. 교체 연출 없음 — 첫 만남 장면의 `[음성 해금]` 패널 1회뿐 |
| 한자 급수가 높은 단어 | 표기한 한자가 상위 급수면 우선 주인공 → 그 한자 급수에 도달하면 담당 인물로 (TOWN_DRAFT §3-6) |
| 처음부터 열림 | 주인공(3종) · 주임 연구원 |
| N5에서 만남 | KURO(B1) · 겐(B2) · 미오(B3) |
| N5에서 잠김 | 스미레(사회) · 스즈(교통 · 이동) · 카이(사물 · 형태) 담당 단어 → 주인공 목소리 |
| 저장 | `met_characters: [id]`, 해금 시각 |

- 판독기 이름표 `声 · {인물}`는 **실제로 재생되는 목소리**의 이름을 보여 줌 (만나기 전이면 `声 · 나`).

## 3. 급수 전환 (N5 → N4 …)

연구소 단계 = 급수 (GAME_DESIGN §5.1). 1단계(N5) 낡은 사무실 한 칸 · 비 → 2단계(N4) 사무실 층 전체 · 흐림.

| 단계 | 조건 / 일 |
| :--- | :--- |
| ① 응시 자격 | 그 급수 단어 **전부를 한 번 이상 졸업** + 그중 **80% 이상이 '안다'(R ≥ 0.90)** |
| ② 알림 | 자격이 되면 출근 때 책상 위에 봉인 봉투 「昇級審査」 (B4-0) |
| ③ 승급 심사 | 그 급수 단어 **30문항** 판독 (같은 판독기, 같은 반응 시간 규칙). 통과 = 졸업 등급(4 이상) **80%** |
| ④ FSRS 반영 | 심사 문항 중 **오늘 복습 예정(due)인 단어만** FSRS에 반영, 나머지는 기록하지 않음 (GAME_DESIGN §4.1-4) |
| ⑤ 불합격 | 패널티 없음, 다음 출근일부터 재응시 (주임 "틀린 건 단말기가 다시 보여 줄 거예요") |
| ⑥ 합격 | 막 완결 장면(N5 = B4) → 다음 출근일에 연구소 2단계 + 다음 급수 새 단어 시작 |
| 이전 급수 | 복습은 계속 (졸업한 급수 단어도 due가 오면 나옴) |

- 새 단어 공급 순서: 목표 급수와 상관없이 **N5부터** (스토리가 1막부터이므로). 이미 N5를 아는 학습자를 위한 '배치 판독'(빠르게 건너뛰기)은 BACKLOG.
- 실제 JLPT 합격 자기 신고(GAME_DESIGN §7)는 승급과 별개 — 엔딩 · 칭호용.

> **확정 P-2** (2026-11-03) — 승급 자격 · 심사 수치. **확정: 전부 1회 졸업 + 80% '안다', 심사 30문항 · 80% 통과.** N5 712단어 · 하루 20개 기준 새 단어만 약 36일 → 5~6주 (N5_SCRIPT "약 5주"와 맞음).
> **확정 P-3** (2026-11-03) — 목표 급수가 N3인 학습자도 N5부터 해야 하나. **확정: 1막은 N5부터 고정, 배치 판독은 P3 이후.**

## 3-1. 판독기 모델 수집 (메타 진행 · P3)

소유자 아이디어 (2026-11-03): 판독기(自炊式 재단기형)를 여러 모델로 두고 **게임 안 화폐로 사서 바꿔 끼울 수 있게**. 옛 일본 사무기기 느낌의 재단기들을 본뜸.

| 항목 | 확정 |
| :--- | :--- |
| 화폐 | **새 코인을 만들지 않고 연구 포인트를 그대로 씀.** 연구 포인트는 이미 GAME_DESIGN §4.1 규칙(같은 날 같은 단어 1회 · 4등급 이상 졸업만 · S 증가분과 복습일을 지킨 복습에 가중)으로만 생김 → 벼락치기 · '쉬움' 남발로 더 벌 수 없음. 자원이 하나면 CORE_LOOP C-2와도 맞음 |
| 모델 차이 | ① **꾸미기**: 몸체 외형 · 색 · 손잡이 모양 · 헤드 스캔 빛 색과 무늬 · 모터 · 손잡이 · 키 · 도장 소리 · 명판 글꼴 · 도장 디자인<br>② **연구 포인트 보너스** (소유자 2026-11-03 허용): 모델마다 획득 배율 **×1.00 ~ ×1.20** (예: 기본기 ×1.00, 상위 모델 +5% · +10% · 최대 +20%) |
| 보너스 계산 | GAME_DESIGN §4.1 무결성 규칙(같은 날 같은 단어 1회 · 4등급 이상 졸업만 · S 증가분 · 복습일 가중)으로 **이미 정해진 연구 포인트에 곱하기만** 함. 졸업하지 않은 판독 · 같은 날 반복 · 연출용 문제에는 0 × 배율 = 0. 배율은 **상한 +20%**, 모델을 여러 대 가져도 쓰는 1대의 배율만 적용 (겹치지 않음) |
| 바꾸면 안 되는 것 | 스캔 **10초 · 4회 통과** · 선명도 단계 · 반응 시간 측정 시점 · 등급표 · 대기열 규칙 · 새 단어 한도. (스캔 시간은 힌트 등급 경계 6초 · 10초와 묶여 있어서, 바꾸면 FSRS 등급이 왜곡됨.) **FSRS 간격 · S · D · due도 모델과 무관.** 보너스는 학습 결과가 아니라 연구 포인트 숫자에만 붙음 |
| 얻는 법 | 연구 포인트로 구매(주임 책상 위 '사무기기 카탈로그' 종이) + 일부는 스토리 보상 (예: 막 완결 · 승급 때 1대). 구매한 모델은 단면 선반에 진열 → 연구소가 채워지는 즐거움 |
| 가격 감각 | 하루 정상 판독(복습 + 새 20) 1~2주치 = 모델 1대. 일부러 길게 공부해야 사지는 않게 상한 없는 고가 모델은 두지 않음. 보너스 모델은 비싸게 (+20% 모델이 본전을 뽑는 데 수개월) → 보너스가 학습 동기를 바꾸지 않을 만큼 작게 |
| 이름 | **실제 브랜드 · 로고 · 모델명 금지** (예: 실존 재단기 회사명 · 형번). 시대 느낌만 빌린 **가상 제조사 · 형번**. 기본기는 스파이크와 같은 「自炊式 判読機 PK-2094」. 후보 예: 쇼와풍 주철 레버식 · 80년대 크림 플라스틱 탁상형 · 90년대 회색 사무용 — 이름은 출시 전 실존 상표와 겹치지 않는지 확인 (GAME_DESIGN §11과 같은 절차) |
| 범위 | 슬라이스는 **기본 모델 1대만**. 구매 · 교체 · 진열은 P3 ([SLICE_SCOPE](SLICE_SCOPE.md) 제외 목록) |

> **확정 P-6** (2026-11-03) — 화폐. **확정: 연구 포인트 하나** (별도 코인 없음).
> **확정 P-7** (2026-11-03, 소유자 수정) — 모델 차이. **확정: 꾸미기 + 연구 포인트 획득 배율 보너스(최대 +20%).** 조건 셋: ① 스캔 시간 · 등급 판정 · FSRS 간격은 절대 바꾸지 않음 ② 보너스는 §4.1 규칙으로 정해진 포인트에 곱하기만 ③ 상한 +20%, 겹치지 않음. 테스트로 고정: 모델을 바꿔도 같은 판독 기록 → 같은 FSRS 결과.
