## 1-2. 앉기 기준점 · 그리기 순서

**의자 · 책상은 인물과 따로 그린다.** 앉았을 때 의자 등받이와 책상 앞판이 인물 **앞**에 그려져야 하므로(인물이 그 사이에 끼어야 함), 한 장으로 그리면 그리기 순서(Depth Sorting)를 나눌 수 없기 때문이다.

| 층 (뒤 → 앞) | 무엇 |
| :--- | :--- |
| 1 뒤 가구 | 의자 좌판 · 다리 · 뒤쪽 다리, 책상 상판 · 뒤판 · 상판 위 물건(CRT · 판독기 덮개 · 스탠드) |
| 2 인물 | 앉은 인물 (다리가 책상 밑으로 들어감) |
| 3 앞 가구 | 의자 **등받이**(인물 등 쪽, 화면 방향에 따라 좌/우) · 책상 **앞판 · 앞다리** (다리를 가림) |

**앉기 기준점 규칙** — 한 벌의 앉기 애니메이션을 모든 의자에 쓰기 위해:

| 규칙 | 값 (아트 픽셀) |
| :--- | :--- |
| 인물 서기 기준점 | 발끝 = 캔버스 (24, 46) (ART_STYLE_SHEET §5.1과 같음) |
| 인물 **엉덩이 기준점** | 앉은 프레임에서 엉덩이 아래 가운데 = 캔버스 **(24, 32)** — 앉은 대기 · 앉기 마지막 프레임 모두 같은 픽셀 |
| 의자 **앉는 자리** | 의자 그림마다 좌판 윗면 가운데 1픽셀을 `seat` 기준점으로 기록 (`chair_*.json` 또는 Godot `Marker2D`) |
| 좌석 높이 표준 | 모든 일반 의자의 `seat`는 **바닥선에서 14px 위** (= 46 − 32) → 앉기 전환 프레임은 발을 바닥에 둔 채로 그려도 엉덩이가 정확히 좌판에 닿음 |
| 놓는 법 | 인물 엉덩이 기준점을 의자 `seat`에 맞춤. 앉기 시작 위치 = `seat` x에서 의자 앞쪽으로 8px |
| 좌석 높이가 다른 의자 | 「源」 스툴처럼 높이가 다르면 **그 높이 전용 앉기 애니메이션** (P3) — 표준 의자는 높이를 바꾸지 않음 |
| 책상과의 거리 | 책상 앞판과 의자 `seat` 사이 가로 12px (무릎이 책상 밑으로 들어가는 거리) |
