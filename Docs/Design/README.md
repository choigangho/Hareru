## 결정 — 2026-11-03 소유자 확정 (모아 보기)

28개 모두 추천안대로 확정, 아래 4가지는 소유자 수정. 이후 추가된 이벤트 결정 V-1~V-9도 추천안대로 확정 (2026-11-03):
- **화폐 이름**: 「연구P」 → **「연구 포인트」**. 세계관 안 일본어 표기 · 발음은 「研究ポイント(けんきゅうポイント)」 — 화면 표시는 '연구 포인트', 대사 · 단말 표기에서는 겐큐포인토 가능.
- **P-7**: 판독기 모델에 연구 포인트 배율 보너스 허용 (곱하기만, 최대 +20%, 스캔 · 등급 · FSRS 불변).
- **A-1**: Day 1 빛을 스탠드 보상과 연결 (스탠드 전 = 화면 빛 · 형광등 하나 · 창밖 간판뿐, 후 = 따뜻하게 밝아짐).
- **폰 대비 규칙 추가** ([ART_STYLE_SHEET §9](ART_STYLE_SHEET.md)): 마우스 오버 전용 금지 · 누름 영역 최소 · 단축키는 보조 · 글자 최소 · 가로 16:9 고정. 로드맵 D1에도 반영.

각 문서 끝에도 같은 표가 있다. **굵은 것**은 시안 작업의 전제가 되는 결정.
