## 0. 한 줄 · 세계관 근거

**한 번 외웠다가 잊은 단어는, 연구소 사람들의 입에서도 하얗게 지워진다.**

- 세계관 이름: **백화(白化)** — STORY_BIBLE §1.1에서 바벨 패치 이후 사람들의 뇌에서 한자 해독이 '하얗게' 퇴화하는 현상. 연구소 안에서는 같은 일이 **당신이 놓친 말**에만 작게 일어난다.
- 연구소 사람들(주임 · KURO · 겐 · 미오)이 육성으로 말할 수 있는 건 '누군가 그 말을 이어 기억하고 있기 때문'이라는 설정 (주임 이름 言継 = 말을 잇다). 주인공이 이어 받은 말을 놓치면 그 말이 대화에서 빠진다.
- 벌이 아니라 **그리움**: GAME_DESIGN §4.1-5 "쉬는 날 패널티 최소화"와 같은 철학. 인물은 화내지 않고, 말이 막혀 머뭇거릴 뿐이다. 판독하면 바로 돌아온다.

## 1. 무엇에 걸리나 (판정 대상)

| 대상 | 말 잃기 적용 | 이유 |
| :--- | :---: | :--- |
| **대사의 일본어 부분** 중 단어 태그가 붙은 단어 | ✅ | 이 규칙의 본체 |
| 대사의 한국어 부분 | ❌ | 스토리 이해는 절대 막지 않음 |
| 판독 문서 (표제어 · 예문 · 음성) | ❌ | 학습 자체를 막으면 안 됨. 판독기는 '말을 되찾는 장치' |
| 아직 **한 번도 졸업하지 않은** 단어 (미학습) | ❌ | '잊은' 게 아니라 '아직 모르는' 말. 인물은 그대로 말함 (대사 규칙 §6.2대로 후리가나 + 뜻) |
| 스토리 필수 줄 (`필수` 표시) | ❌ | §4 예외 |
| 연구소 소품 · 간판 라벨 | (P3) | 같은 판정 함수를 재사용 — BACKLOG |

**"기억하는 단어"의 뜻**: 한 번이라도 판독을 졸업(4등급 이상)해서 FSRS 기록이 있는 단어. 미학습 단어는 세계가 이미 가진 말이고, 말 잃기는 *당신이 쥐었다가 놓친* 말에만 걸린다.

> **확정 S-1** (2026-11-03) — 표어를 엄격하게 읽어 "미학습 단어도 일본어로 말하지 못함(한국어로만)"으로 할지. **확정: 하지 않음.** D1 대사만 해도 本当 · 来る 같은 미학습 단어가 일본어로 나오고, GAME_DESIGN §6.2 대사 비율(한 80 · 일 20)이 이미 '어려운 말은 일본어로 쓰지 않음'을 대본 단계에서 걸러 준다. 엄격판은 대본 전체를 다시 써야 함.

## 2. 판정 기준 (FSRS 값)

판정은 **기억 유지율 R**(retrievability)로 한다. 스파이크 `FSRS.retrievability(elapsed_days, S)` = `(1 + 19/81 · t/S)^-0.5`, 목표 유지율 0.90.

| 상태 | 조건 | 경과일로 보면 | 대사에서 |
| :--- | :--- | :--- | :--- |
| **미학습** | FSRS 기록 없음 | — | 그냥 일본어 (강조 없음) |
| **선명** | R ≥ 0.90 (= 복습 예정일 전) | t < S | 『』 강조 · 누르면 뜻. "알아듣는 기쁨" (§6.2) |
| **흐려짐** | 0.80 ≤ R < 0.90 (= 복습일이 지났음) | S ≤ t < 2.4·S | 『』 강조가 빠지고 글자가 한 단계 흐림 (디더). 음성은 그대로 |
| **백화** | R < 0.80 | t ≥ 2.4·S | 인물이 그 단어를 **말하지 못함** (§3) |
| **오늘 잊음** | 오늘 판독에서 그 단어가 AGAIN · HARD를 받고 아직 다시 졸업하지 않음 | — | 백화와 같음 (그날 졸업하면 즉시 선명) |

- R = 0.90 경계는 FSRS가 복습일을 잡는 기준(due ≈ S일 뒤)과 같아서 **"복습일이 지났다 = 흐려진다"** 로 플레이어가 이해하기 쉽다.
- 백화 경계 0.80은 복습일을 S의 1.4배만큼 더 넘긴 때. 예: 처음 외운 단어(S ≈ 1일) → 2~3일 안 오면 백화. 오래 외운 단어(S = 10일) → 24일 뒤.
- 판정 시각은 **장면이 시작되는 순간 한 번** 계산해서 장면이 끝날 때까지 고정 (말하던 중에 상태가 바뀌지 않게).
- 함수는 순수 함수로: `speech_state(word_id, progress, now, today_failures) → enum` — 창 없는 테스트로 고정 (P2).

> **확정 S-2** (2026-11-03) — 경계값. **확정: 흐려짐 R < 0.90, 백화 R < 0.80.** 더 너그럽게 하려면 백화 R < 0.70 (t ≥ 4.4·S).

## 3. 표현 — 대사 · 화면 · 소리

예: 겐의 줄 「『ご飯』、ちゃんと 食べたか?」 에서 ご飯이 백화일 때.

| 층 | 선명 | 백화 |
| :--- | :--- | :--- |
| **글자** | 『ご飯(はん)』 강조 | 단어 자리가 **같은 글자 수의 하얀 칸** `□□` (픽셀 종이 흰색, 가장자리 1px 크림). 후리가나 자리도 비움 |
| **인물** | 평소 표정 | 그 줄만 `머뭇` 연출: 초상이 1프레임 멈칫 + 말끝 「…」 (새 표정 그림 없이 초상 흔들림 · 시선 내림은 코드로) |
| **음성** | 줄 음성 재생 | **그 줄은 음성을 재생하지 않음** + 짧은 테이프 늘어지는 소리(공용 효과음 1개) |
| **한국어 뜻** | 탭하면 전체 | 탭하면 전체 — 지워진 단어도 한국어에선 그대로 보임 (이해 보장) |
| **하얀 칸을 누름** | — | 「판독 기록이 흐려졌어요 · 복습 예정 {n}일 지남」 작은 쪽지. **뜻은 보여 주지 않음** (스스로 떠올릴 기회) |
| **되찾음** | — | 그 단어를 판독으로 다시 졸업하면, 다음에 그 단어가 나오는 줄에서 하얀 칸이 **모자이크 해독 효과**로 채워지며 『』 강조 (1회만) |

- 음성은 줄 단위로 미리 합성된 파일이라 단어 하나만 지울 수 없다 → **줄 전체 무음**이 현실적. 단어 구간만 잡음 처리하려면 단어별 타임스탬프가 필요 (BACKLOG).
- 하얀 칸 개수 제한: **한 줄에 최대 1개, 한 장면에 최대 3줄.** 그 이상 백화된 단어가 있어도 나머지는 '흐려짐'으로 표시 (화면이 하얀 칸 투성이가 되지 않게). 고르는 순서: R이 가장 낮은 단어 먼저.
- 판독 장면의 주임 CRT 한마디 · 시스템 문구 · 선택지는 적용하지 않음 (조작 안내가 지워지면 안 됨).

## 4. 예외

| 예외 | 규칙 |
| :--- | :--- |
| **스토리 필수 줄** | lines 데이터 `비고`에 `필수`가 있는 줄은 말 잃기 없음. 반전 · 복선 · 조작 안내 줄 (예: B4 레시피 노트 문장, D1 퇴근 「また、あした。」) |
| **튜토리얼 · 첫 만남 장면** | D1 전체, B1~B3 첫 만남 장면은 말 잃기 없음 (인물 소개가 깨지면 안 됨) |
| **시험 대비 집중 모드** | 대화가 아예 나오지 않음. 보관함에서 나중에 볼 때는 **볼 때의 상태**로 판정 |
| **고유 명사 · 이름** | 태그 대상 아님 (人名 · 「源」 등) |
| **감탄사 · 인사 최소 세트** | はい · いいえ · すみません · ありがとう 등 **기초 인사 목록**은 백화 대신 흐려짐까지만 (말이 아예 안 통하는 느낌 방지) — 목록은 P2 데이터로 |
| **연출 · 보상과 분리** | 말 잃기는 연구 포인트 · 호감도 · 해금을 깎지 않는다. FSRS 기록을 읽기만 함 |

## 5. 데이터에 필요한 것

- lines 표에 **`단어` 열 추가**: 그 줄의 일본어에 나오는 학습 단어의 word id 목록과 위치. 예: `n5_xxx@2-4` (일본어 문자열의 글자 범위).
  - D1은 사람이 직접 태그 (일본어가 있는 줄 32개 — 주임 18 · 주인공 13 · 시스템 1). N5 전체는 형태소 분석 보조 도구로 (BACKLOG).
  - 태그가 없는 줄은 말 잃기 판정을 하지 않음 → 데이터가 늦어도 게임이 깨지지 않음.
- 『』 강조(선명 상태)도 같은 태그를 쓴다 → 강조와 백화가 **같은 데이터 · 같은 함수**에서 나옴.
- 이 열은 스토리 원본(`Docs/03_Story/Acts/N5/lines/`) 소관 → 스토리 세션 작업 (P2 착수 전 D1만).

### 5.1 반영 현황 (2026-11-03, 스토리 세션 `196eb28`)

- 모든 lines 표에 `단어` 열이 생김 (한국어와 비고 사이). D1은 일본어 줄 32개 중 학습 단어가 있는 **21줄** 태그 완료.

## 6. Day 1에서 어디까지 보여 주나

**Day 1에는 백화가 자연스럽게 일어날 수 없다** (첫 실행이라 잊은 단어가 없음). 그래서 Day 1은 규칙의 **좋은 쪽 절반**만 보여 준다.

| Day 1에서 | 보여 줌 | 예 |
| :--- | :---: | :--- |
| 선명 → 『』 강조 | ✅ | T-2에서 分かる를 졸업한 뒤 주임 「『わかります』か?」, T-6 이후 はい · いいえ가 나오는 줄 |
| 흐려짐 · 백화 | ❌ | 처음 백화가 가능한 날은 2일차 이후 (S ≈ 1일 → 2~3일 결근 시) |
| 복선 한 줄 | ✅ (기존 대사) | T-9 주임 "잊을 때쯤 다시 보는 게 제일 잘 남거든요" — 대사 추가 없이 그대로 |
| 판정 함수 · 하얀 칸 렌더 | ✅ (구현만) | 슬라이스에서 구현 · 테스트하고, 개발용 날짜 건너뛰기(`--days=+5`)로 화면 확인 |

**처음 백화를 플레이어가 만나는 곳 (반영됨)**: N5_SCRIPT **R4 (3일 이상 쉬다 복귀)** R4-013a~e. 주임이 『{잊은말}』을 꺼내지 못해 하얀 칸 → "…어라, 그 말이 안 나오네요." → "같이 다시 판독해요." `{잊은말}` = 그 시점 R이 가장 낮은 백화 단어, 백화 단어가 없으면 이 줄들은 생략. 변수가 든 줄이라 `{이름}` 줄과 같이 **음성 없이 글자만** (SLICE_ASSETS §7.2).
