## 4. 《Cytus II》 스타일 단말기 연출 & 제4의 벽 · 집중 모드

### 4.1 학습 중 발생하는 단말기 글리치 & 스토리 해금 연출
- 단말기 OS(`NJL-OS`)로 단어를 학습하던 중, 핵심 스토리 카드(예: N3 `諦める`, 대분류 첫 진입 등)나 마일스톤에 도달하면 **《Cytus II》처럼 화면에 순간적인 픽셀 글리치·신호 간섭(`WARNING: MEMORY FRAGMENT DETECTED`)**이 일어남.
- 글리치와 함께:
  1. 주인공의 지워진 과거 기억 파편이나 픽셀 캠코더 화면이 3~5초간 스쳐 지나감.
  2. 흑막이 KURO나 원내 방송 AI를 해킹해 **VOICEVOX Voidoll(`vv:89`)** 목소리로 경고를 보내거나, 과거의 자신이 심어둔 백도어 로그가 열림.

### 4.2 전 탭(통계 · 설정 · 연구소) 유기적 상호작용 & 제4의 벽(4th Wall) 돌파
- **통계 탭 상호작용**: 학습 잔디(캘린더)나 기억 안정도 그래프의 특정 노이즈 지점을 탭하면, 단순 통계가 아니라 **2079년 바벨 패치 당시의 숨겨진 연구 일지**나 과거 보이스 로그가 열림.
- **설정 탭 상호작용**: 설정 화면에 세계관 항목(예: `뉴럴링크 백그라운드 동기화`, `기억 소거 프로토콜 보호막`)이 섞여 있어, 이를 조작하려 하면 KURO나 주임 연구원이 대사로 개입함.
- **제4의 벽(4th Wall) 연출**: 심야 접속이나 특정 조건에서 주임 연구원이나 KURO가 게임 속 신입을 넘어 **스마트폰 화면 너머에서 실제로 일본어를 외우고 있는 '플레이어 본인'**에게 말을 거는 듯한 메타 연출 등장.

### 4.3 수험생을 위한 안전장치: **『시험 대비 집중 모드 (Exam Focus Mode)』**
- **도입 배경**: 당장 JLPT 시험 준비가 급한 학습자에게는 글리치 연출이나 스토리 대화가 병목이 될 수 있음.
- **작동 방식**:
  - 상단(또는 설정)의 **『집중 모드』** 스위치를 켜면 학습 중 일체의 글리치·대사·이벤트 개입이 즉시 차단되어 순수 FSRS 초고속 학습만 진행됨.
  - 집중 모드 중 달성한 스토리와 캐릭터 해금은 증발하지 않고 연구소 탭의 **『미확인 기록 보관함(Archive Queue)』**에 적립되어, 시험이 끝난 뒤 언제든 몰아서 열람할 수 있음.

## 5. UI/UX 원칙: 고급 동적 픽셀 UI (`NJL-OS`)

### 5.1 Liquid Glass 전면 폐기 → 연구소 단말기 컨셉 통일
- 기존의 반투명 유리(Liquid Glass)를 버리고, **앱 전체(학습 · 연구소 · 통계 · 설정)를 연구소 단말기 컨셉의 고급 동적 픽셀 UI**로 통일.

### 5.2 디자인 핵심 원칙
1. **픽셀 고딕 + 픽셀 명조 혼합 타이포그래피**:
   - **표제어·예문 본문·회상 자막**: 서정적인 **픽셀 명조체** 사용.
   - **후리가나·UI 라벨·수치·시스템 로그**: 판독성이 뛰어난 **픽셀 고딕체** 사용.
2. **픽셀 모자이크(Pixel Mosaic) 10초 디코딩 연출**:
   - 학습 카드 앞면의 10초 힌트 페이드를 단순 블러 대신 **'QR 매트릭스형 픽셀 모자이크 → 단계별 도트 분해 → 선명한 글자'** 애니메이션으로 구현.
3. **고급 동적 픽셀 UI (Dynamic Pixel Craft)**:
   - 도트 그래픽이지만 움직임은 60fps 스프링 탄성과 물리감을 가지며, 시간대·날씨(OKLCH 팔레트)의 환경광이 픽셀 프레임 테두리에 실시간 반영됨.
