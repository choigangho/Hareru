## 0. 공통 원칙

1. **학습을 막지 않는다.** 판독 도중에 끼어드는 건 '겹쳐 보이는 한두 마디'(오버레이)뿐. 장면은 판독 앞뒤에만.
2. **FSRS를 건드리지 않는다.** 어떤 이벤트도 등급 · 간격 · 대기열 · 반응 시간 측정을 바꾸지 않는다. 이벤트는 기록을 **읽기만** 한다 (GAME_DESIGN §4.1-1).
3. **이벤트는 연구 포인트를 주지 않는다.** 연구 포인트는 판독 졸업에서만 생긴다 (§4.1). 이벤트 보상은 대사 · 소품 · 도장 모양 · 장식 같은 **꾸미기**뿐 (결정 V-4).
4. **벌주지 않는다.** 틀림 · 결근 · 연속 끊김에 꾸짖거나 무언가를 빼앗는 연출 없음 (§4.1-5, R4 "화내지 않고 반김").
5. **짧고, 건너뛸 수 있다.** 대본 필수 장면을 빼면 모든 이벤트는 건너뛸 수 있다. 건너뛰어도 결과(소품 설치 등)는 그대로 적용.
6. **집중 모드에서는 꺼진다.** §6 참고.
7. **같은 날 다시 켜도 같은 결과.** 확률 이벤트는 날짜(4시 경계)로 정한 난수를 써서, 껐다 켜며 다시 뽑을 수 없게 한다.

## 1. 신호 → 이벤트 감독 → 슬롯

```
게임 신호 ──▶ 이벤트 감독 ──▶ 조건 · 쿨다운 · 상한 확인 ──▶ 슬롯에 배치 ──▶ 재생 ──▶ 기록(본 날짜 · 횟수)
```

| 신호 (게임이 보냄) | 언제 |
| :--- | :--- |
| `workday_started` | 출근 (그날 처음 연구소에 들어옴) |
| `doc_rated(word, key, grade)` | 판독 문서 하나 평가 끝 (도장 찍힌 뒤, 다음 문서 끼우기 전) |
| `word_graduated(word, was_blank)` | 졸업. `was_blank` = 장면 시작 시 말 잃기 '백화'였던 단어 |
| `queue_emptied` | 오늘 더미가 빔 |
| `reader_left` | 판독 장면에서 일어섬 |
| `scene_finished(id)` | 대본 장면 · 컷신 끝 |
| `lab_idle(seconds)` | 연구소에서 아무것도 안 누른 채 시간이 지남 |
| `workday_ending` | 퇴근 문을 누름 |

### 1.1 슬롯 (어디에 끼우나)

| 슬롯 | 위치 | 길이 | 상한 | P-4와의 관계 |
| :--- | :--- | :--- | :--- | :--- |
| **앞 장면** | 출근 직후, 판독 전 | 1~3분 | 하루 1 | P-4 '판독 앞 1' 그 자체 |
| **뒤 장면** | 판독 사이클 끝 · 일어선 뒤 | 1~3분 | 하루 2 | P-4 '판독 뒤 2' 그 자체 |
| **오버레이** | 판독 중 — 평가 후 다음 문서 전, 주임 CRT 한두 마디 | 5초 이하 | 하루 3 | 장면 수에 안 셈. 다음 문서의 반응 시간 시계는 오버레이가 끝난 뒤 시작 |
| **소동** | 연구소 자유 행동 중, 대사 없거나 한 줄 | 20초 이하 | 하루 1 | 장면 수에 안 셈 (결정 V-7) |
| **장식** | 연구소 배경 소품 (그날 내내) | — | 제한 없음 | 장면 아님 |

- 한 슬롯에 후보가 여러 개면 **우선순위**가 높은 것 하나. 밀린 것은 다음 출근일로 미룸 (계절 이벤트는 기간이 끝나면 버림).

## 2. 범주별 설계

### 2.1 계속 틀릴 때 (돕는 연출)

대본 R1을 기준으로 하고, 용어는 판독기 키 이름인 **'모르겠음'**으로 쓴다 (대본의 '모른다'는 스토리 세션에 수정 요청 — README K-3).

| id | 조건 | 슬롯 | 무엇을 하나 | 쿨다운 · 상한 |
| :--- | :--- | :--- | :--- | :--- |
| `struggle_first` (= R1) | 처음으로 **'모르겠음' 키를 3장 연속** (다른 단어 3장) | 오버레이 (대사 6줄이라 예외적으로 길이 허용, 판독은 멈추지 않고 다음 문서를 그 뒤에 끼움) | 주임 `미소` 위로 — 대본 R1 그대로 | 평생 1회 |
| `struggle_streak` | 이후 '모르겠음' **5장 연속** | 오버레이 | 주임 한 줄: "괜찮아요, 곧 또 나와요." / "모르는 게 정상인 단어예요." (R1 끝 랜덤 줄) | 판독 20장마다 1회 · 하루 2 |
| `struggle_same_word` | **같은 단어**가 오늘 '모르겠음' 3번째 | 오버레이 + **판독기 스피커 LED 깜빡** | 주임: "예문을 한 번 소리 내서 들어 볼래요?" — 스피커(`R` / 누르기)를 권함. 누르지 않아도 그만 | 같은 단어 하루 1회 · 하루 3 |
| `struggle_tired` | **최근 10장 중 6장 이상**이 모르겠음 · 애매함 | 오버레이 → 선택 | 주임: "차 한 잔 하고 올까요?" — [계속할게요] [잠깐 쉬기]. 쉬기 = 일어서기와 같음 (판독 전 문서는 더미로, 시계 무효 — CORE_LOOP §2.2) | 하루 1 |

규칙:
- **힌트는 판독(손잡이) 후에만.** 판독 전에 힌트를 주면 반응 시간 등급이 의미를 잃는다. 판독 후 힌트 = 예문 다시 듣기 권유 · 주임 한 줄 기억 요령(데이터에 있을 때만).
- 대기열 재삽입 위치(2장 뒤 · 4장 뒤 · 맨 뒤) · 하루 8회 상한 · 등급표는 그대로.
- 대사에 '틀렸다 · 실패 · 점수' 같은 말을 쓰지 않음. 주인공 `민망`까지는 괜찮고, 주임은 `미소` · `기본` · `난감`(자기 얘기할 때)만.
- 대본 R1의 "내일 다시 보여 줄 거예요"는 실제 규칙(모르겠음 → 2장 뒤 다시)과 다름 → "곧 다시 보여 줄 거예요"로 고치도록 스토리 세션에 요청 (README K-13).

### 2.5 스토리 컷신

카메라 · 인물 행동 · 조명 · 소리 · 대사를 **한 줄씩 순서대로** 적은 연출 데이터. 대사는 lines의 줄 ID로 참조.

| 연출 단위 | 쓸 수 있는 것 |
| :--- | :--- |
| 카메라 | 이동(아트 픽셀 단위) · 확대(**정수배만** — ART_STYLE_SHEET §1.3) · 컷 · 흔들림(움직임 줄이기면 끔) |
| 인물 | [SLICE_ASSETS §1-1](../05_Art/SLICE_ASSETS.md) 행동 표의 행동 + 목표 위치 (걷기는 자동) |
| 조명 | `lab_light_layers` 상태 전환 (스탠드 전 / 후 / 밤) + 전환 시간 |
| 소품 | 상태 바꾸기 (스탠드 없음 → 켜짐, 게시판 1 → 2 …) |
| 소리 · 대사 | 효과음 ID · lines 줄 ID |
| 기다림 | 초 · 입력 대기 |

### 2.6 트라우마 단어 — 심리 연출 (소유자 추가 2026-11-03)

주인공의 **지워진 기억**(기억 소거 시술 · 2079년 비 오는 여름 · 아버지의 「あきらめろ」 · 잃은 가족)에 닿는 단어를 판독하면, 화면이 붉어지고 소리가 일그러지는 **불안 · 공포 연출**이 나온다. STORY_BIBLE §4.1 '단말기 글리치'와 N5_SCRIPT §1의 3단계 '멈추는 문서'(N3 諦める)로 이어지는 같은 계열을, 그 아래 단계부터 쌓아 올리는 것.

**톤**: 깜짝 놀래기(점프 스케어) · 피 · 신체 훼손 없음. 《애프터썬》식 '설명하기 어려운 불안'에 가까운 **심리적 공포** — 주인공 몸의 반응(이명 · 심장 · 시야가 좁아짐)으로 보여 준다.

| 단계 | 언제 | 화면 | 소리 | 인물 |
| :---: | :--- | :--- | :--- | :--- |
| **약** | 트라우마 단어를 판독할 때마다 (N5부터) | 가장자리 비네트가 **붉게 한 번 맥박** (1초) · 종이 글자가 1px 떨림 | 빗소리가 잠깐 커짐 · 낮은 이명 | 없음 |
| **중** | 그 단어를 **처음** 판독할 때 / 핵심 단어 | 화면 전체가 **붉게 물듦**(색 반전 아님, 붉은 곱하기 층) · 시야가 좁아짐(비네트 수축) · 2079.07 노이즈 칸 같은 깨진 글자가 종이 위로 0.5초 · 렉스코드 시안 잔상 | 심장 박동 2~3번 · 이명 · 테이프 늘어짐 | 판독 후 주임 CRT가 **말없이** 주인공을 봄 (`진지`), 다음 문서 전에 한 줄 "…괜찮아요?" |
| **강** | 대본이 정한 단어만 (= 3단계 멈추는 문서, N3 諦める) | N5_SCRIPT §1.1 그대로 — 헤드가 걸리고 손잡이가 안 내려감, 캠코더 화질 회상 | 「あきらめろ」 | 이후 연구소 장면 |

- **어떤 단어가 트라우마 단어인가**: 단어 데이터에 `trauma` 태그(약 · 중 · 강)를 **스토리 원본이 정함** (자동 판정 아님). **N5 확정 12개** (N5_SCRIPT §4.1, 2026-11-03): **중** 雨 · 夏 · 家族 · 病院 · 忘れる / **약** 父 · お父さん · 母 · お母さん · 手 · 薬 · 傘. 名前(Day 1 문서)와 형제 단어(주임 반전 보호)는 제외. 데이터: words.json `trauma` 필드 = `"mid"`(중) · `"low"`(약), 없으면 생략 — 원본은 `Tools/drafts` 각 단어 항목, `export_catalog.py`가 mid/low만 허용 (2026-11-03 반영). '강'은 단어 필드가 아니라 대본이 정한 멈추는 문서. 그 단어의 **예문**은 평범한 일상 그대로 (공포는 예문 내용이 아니라 주인공의 반응).
- **FSRS 무결성**: 연출은 **손잡이를 당긴 뒤(판독 후)** 에만 시작 → 반응 시간 측정에 영향 없음. '중'의 한 줄 대사는 오버레이 슬롯 — 다음 문서 시계는 연출이 끝난 뒤 시작. 등급 · 간격 · 대기열 불변.
- **빈도**: '중'은 단어마다 평생 1회(이후 '약'), '약'은 하루 최대 5회 · 연속 두 장이면 두 번째는 생략. 한 판독 사이클에 '중'은 최대 1회.
- **이야기와의 연결**: '중'을 본 횟수 · 단어가 기억 복원 단서로 쌓임 (STORY_BIBLE §2.2 암기량 ∝ 기억 복원). 기록 클립보드의 노이즈 칸이 조금씩 늘어나는 식으로 보여 줄 수 있음 (P3).
- **안전 · 접근성** (필수):
  - **빠른 깜빡임 금지** — 밝기 변화는 초당 3회 미만 (광과민성 발작 기준). '붉게 맥박'은 서서히 오르내리는 한 번.
  - 단말 설정에 **「강한 연출 줄이기」** 스위치: 켜면 붉은 층 · 시야 좁힘 · 심장 소리 없이 '약'(비네트 살짝)만. '움직임 줄이기'를 켜면 떨림 · 잔상도 꺼짐.
  - 첫 실행 초기 설정에 짧은 안내: "이 게임에는 불안감을 주는 연출이 있어요" + 위 스위치로 바로 가기.
  - 집중 모드에서는 '약' · '중' 모두 꺼짐 ('강'은 대본 규칙대로 문서만 평범하게 · 장면은 보관함).

> **확정 V-8** (2026-11-03) — 트라우마 연출 강도 단계. **확정: 약 · 중 · 강 3단계, 깜짝 놀래기 · 고어 없음, 판독 후에만 시작.**
> **확정 V-9** (2026-11-03) — 트라우마 단어 목록을 누가 정하나. **확정: 스토리 세션이 단어 데이터 `trauma` 태그로 (N5는 10개 안팎).** 슬라이스(Day 1)에는 넣지 않음 — Day 1 판독 20단어에 트라우마 단어를 넣지 않고, T-4 2079.07 노이즈 칸이 Day 1의 유일한 불안 연출.

## 3. 이벤트 데이터 표 — 열 초안

이벤트는 표 한 줄 = 데이터 한 건. Tools 파이프라인에서 JSON으로 내보냄 (P2). 코드는 '조건 종류'와 '연출 단위'만 알고, 이벤트 하나하나는 모름.

| 열 | 뜻 | 예 (`struggle_same_word`) |
| :--- | :--- | :--- |

| `우선순위` | 0 ~ 4 (§1.2) | 3 |
| `슬롯` | 앞 장면 · 뒤 장면 · 오버레이 · 소동 · 장식 | 오버레이 |

| `집중 모드` | 끔 · 보관함으로 | 끔 |
| `대사 참조` | lines 줄 ID 목록 또는 랜덤 풀 ID | `EV-STRUGGLE-01~03` |
